MINOR TEST 12
Class: 10 CBSE Subject: Mathematics (Trigonometry) Time: 1 Hour Max. Marks: 50
General Instructions:
  • The question paper consists of 15 questions divided into three sections A, B, and C.
  • All questions are compulsory.
  • Section A comprises 5 questions of 2 marks each.
  • Section B comprises 5 questions of 3 marks each.
  • Section C comprises 5 questions of 5 marks each.
  • There is no overall choice. However, internal choices may be provided in select questions.
  • Write your answers neatly and legibly. Use of calculators is prohibited.
SECTION A (10 Marks)(Very Short Answer Type - Attempt all questions - 2 Marks Each)
1.
If \(\sin \theta = \frac{3}{5}\), calculate the value of \((\tan \theta + \sec \theta)\).
2.
Evaluate the following:
\[ 2 \tan^2 45^\circ + \cos^2 30^\circ - \sin^2 60^\circ \]
3.
Prove that: \((1 - \sin^2 A)\sec^2 A = 1\).
4.
Given \(15 \cot A = 8\), find the value of \(\sin A\).
5.
Evaluate:
\[ \frac{2 \tan 30^\circ}{1 + \tan^2 30^\circ} \]
SECTION B (15 Marks)(Short Answer Type - Attempt all questions - 3 Marks Each)
6.
Prove that:
\[ \frac{\cos A}{1 + \sin A} + \frac{1 + \sin A}{\cos A} = 2 \sec A \]
7.
Prove that:
\[ (\sin A + \text{cosec } A)^2 + (\cos A + \sec A)^2 = 7 + \tan^2 A + \cot^2 A \]
8.
In right triangle \(\triangle PQR\), right-angled at \(Q\), it is given that \(PR + QR = 25 \text{ cm}\) and \(PQ = 5 \text{ cm}\). Determine the values of \(\sin P, \cos P\) and \(\tan P\).
9.
Prove that:
\[ \sqrt{\frac{1 + \sin A}{1 - \sin A}} = \sec A + \tan A \]
10.
Prove that:
\[ \frac{\sin \theta - 2\sin^3 \theta}{2\cos^3 \theta - \cos \theta} = \tan \theta \]
SECTION C (25 Marks)(Long Answer Type - Attempt all questions - 5 Marks Each)
11.
Prove that:
\[ \frac{\tan \theta}{1 - \cot \theta} + \frac{\cot \theta}{1 - \tan \theta} = 1 + \sec \theta \text{ cosec } \theta \]
12.
Prove the following identity using the identity \(\text{cosec}^2 A = 1 + \cot^2 A\):
\[ \frac{\cos A - \sin A + 1}{\cos A + \sin A - 1} = \text{cosec } A + \cot A \]
13.
Evaluate the following accurately without using trigonometric tables:
\[ \frac{\sin 30^\circ + \tan 45^\circ - \text{cosec } 60^\circ}{\sec 30^\circ + \cos 60^\circ + \cot 45^\circ} \]
14.
If \(\sec \theta + \tan \theta = p\), then show that:
\[ \frac{p^2 - 1}{p^2 + 1} = \sin \theta \]
15.
Prove that:
\[ (\text{cosec } \theta - \cot \theta)^2 = \frac{1 - \cos \theta}{1 + \cos \theta} \]
