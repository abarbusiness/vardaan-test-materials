Minor Test 12: Profit and Loss
Class: 7 ICSE | Subject: Mathematics | Max Marks: 40
SECTION A (10 Marks)
Q1. Find the profit or loss if CP = \( \text{₹ } 500 \) and SP = \( \text{₹ } 620 \).
[2 M]
Solution:
Given, CP = \( \text{₹ } 500 \) and SP = \( \text{₹ } 620 \).
Since SP > CP, there is a profit.
Profit = SP - CP = \( 620 - 500 = \text{₹ } 120 \) (2 Marks)
Ans: Profit of ₹ 120
Q2. A toy was bought for \( \text{₹ } 250 \) and sold at a loss of \( \text{₹ } 30 \). Find the selling price.
[2 M]
Solution:
Given, Cost Price (CP) = \( \text{₹ } 250 \)
Loss = \( \text{₹ } 30 \)
Selling Price (SP) = CP - Loss (1 Mark)
SP = \( 250 - 30 = \text{₹ } 220 \) (1 Mark)
Ans: ₹ 220
Q3. Calculate the loss percent if CP = \( \text{₹ } 400 \) and SP = \( \text{₹ } 360 \).
[2 M]
Solution:
CP = \( \text{₹ } 400 \), SP = \( \text{₹ } 360 \)
Loss = CP - SP = \( 400 - 360 = \text{₹ } 40 \) (1 Mark)
\( \text{Loss \%} = \left( \frac{\text{Loss}}{\text{CP}} \right) \times 100 \)
\( = \left( \frac{40}{400} \right) \times 100 = 10\% \) (1 Mark)
Ans: 10%
Q4. Ravi bought a pen for \( \text{₹ } 80 \) and sold it for \( \text{₹ } 100 \). Find his profit percent.
[2 M]
Solution:
CP = \( \text{₹ } 80 \), SP = \( \text{₹ } 100 \)
Profit = SP - CP = \( 100 - 80 = \text{₹ } 20 \) (1 Mark)
\( \text{Profit \%} = \left( \frac{20}{80} \right) \times 100 = \left( \frac{1}{4} \right) \times 100 = 25\% \) (1 Mark)
Ans: 25%
Q5. CP = \( \text{₹ } 1200 \) and desired profit = \( \text{₹ } 150 \). What should be the selling price?
[2 M]
Solution:
Cost Price (CP) = \( \text{₹ } 1200 \)
Profit = \( \text{₹ } 150 \)
Selling Price (SP) = CP + Profit (1 Mark)
SP = \( 1200 + 150 = \text{₹ } 1350 \) (1 Mark)
Ans: ₹ 1350
SECTION B (15 Marks)
Q6. Bought apples for \( \text{₹ } 1200 \), spent \( \text{₹ } 100 \) on transport. Sold for \( \text{₹ } 1560 \). Find profit %.
[3 M]
Solution:
Total Cost Price = Purchase Price + Overhead Charges
Total CP = \( 1200 + 100 = \text{₹ } 1300 \) (1 Mark)
Selling Price (SP) = \( \text{₹ } 1560 \)
Profit = SP - Total CP = \( 1560 - 1300 = \text{₹ } 260 \) (1 Mark)
\( \text{Profit \%} = \left( \frac{\text{Profit}}{\text{Total CP}} \right) \times 100 = \left( \frac{260}{1300} \right) \times 100 = 20\% \) (1 Mark)
Ans: 20%
Q7. By selling a watch for \( \text{₹ } 990 \), shopkeeper gains \( 10\% \). Find CP.
[3 M]
Solution:
Selling Price (SP) = \( \text{₹ } 990 \)
Gain (Profit) = \( 10\% \)
We know, \( \text{CP} = \left( \frac{100}{100 + \text{Gain}\%} \right) \times \text{SP} \) (1 Mark)
\( \text{CP} = \left( \frac{100}{100 + 10} \right) \times 990 \)
\( \text{CP} = \left( \frac{100}{110} \right) \times 990 \) (1 Mark)
\( \text{CP} = 100 \times 9 = \text{₹ } 900 \) (1 Mark)
Ans: ₹ 900
Q8. Bought bicycle for \( \text{₹ } 1500 \), sold at \( 20\% \) loss. Find SP.
[3 M]
Solution:
Cost Price (CP) = \( \text{₹ } 1500 \)
Loss = \( 20\% \)
Loss amount = \( 20\% \) of \( 1500 = \left( \frac{20}{100} \right) \times 1500 = \text{₹ } 300 \) (1.5 Marks)
Selling Price (SP) = CP - Loss amount
\( \text{SP} = 1500 - 300 = \text{₹ } 1200 \) (1.5 Marks)
Ans: ₹ 1200
Q9. If CP of \( 10 \) pens = SP of \( 8 \) pens, find gain %.
[3 M]
Solution:
Let the Cost Price (CP) of 1 pen be \( \text{₹ } 1 \).
Then, CP of 10 pens = \( \text{₹ } 10 \).
CP of 8 pens = \( \text{₹ } 8 \).
According to question: SP of 8 pens = CP of 10 pens = \( \text{₹ } 10 \) (1 Mark)

For 8 pens:
CP = \( \text{₹ } 8 \)
SP = \( \text{₹ } 10 \)
Gain = SP - CP = \( 10 - 8 = \text{₹ } 2 \) (1 Mark)

\( \text{Gain \%} = \left( \frac{\text{Gain}}{\text{CP}} \right) \times 100 = \left( \frac{2}{8} \right) \times 100 = 25\% \) (1 Mark)
Ans: 25%
Q10. Dealer bought chair for \( \text{₹ } 600 \). At what price to sell to gain \( 15\% \)?
[3 M]
Solution:
Cost Price (CP) = \( \text{₹ } 600 \)
Gain % = \( 15\% \)
Gain amount = \( 15\% \) of \( 600 = \left( \frac{15}{100} \right) \times 600 = \text{₹ } 90 \) (1.5 Marks)
Selling Price (SP) = CP + Gain amount
\( \text{SP} = 600 + 90 = \text{₹ } 690 \) (1.5 Marks)
Ans: ₹ 690
SECTION C (15 Marks)
Q11. Sold for \( \text{₹ } 1200 \) at \( 20\% \) loss. (a) Find CP. (b) Find SP for \( 10\% \) gain.
[5 M]
Solution:
(a) Given, SP = \( \text{₹ } 1200 \), Loss = \( 20\% \)
\( \text{CP} = \left( \frac{100}{100 - \text{Loss}\%} \right) \times \text{SP} \) (1 Mark)
\( \text{CP} = \left( \frac{100}{100 - 20} \right) \times 1200 = \left( \frac{100}{80} \right) \times 1200 \)
\( \text{CP} = 100 \times 15 = \text{₹ } 1500 \) (2 Marks)

(b) Now, CP = \( \text{₹ } 1500 \) and required Gain = \( 10\% \)
New SP = \( \text{CP} \times \left( \frac{100 + \text{Gain}\%}{100} \right) \)
New SP = \( 1500 \times \left( \frac{110}{100} \right) = 15 \times 110 = \text{₹ } 1650 \) (2 Marks)
Ans: (a) CP = ₹ 1500, (b) New SP = ₹ 1650
Q12. Bought 240 eggs at \( \text{₹ } 15 \) per dozen. 20 broken. Sold rest at \( \text{₹ } 1.50 \) each. Find (a) Total CP (b) Total SP (c) Profit/Loss %.
[5 M]
Solution:
(a) Total Cost Price:
Total eggs = \( 240 \)
Number of dozens = \( \frac{240}{12} = 20 \text{ dozens} \)
Total CP = \( 20 \times 15 = \text{₹ } 300 \) (1 Mark)

(b) Total Selling Price:
Broken eggs = \( 20 \). Remaining eggs = \( 240 - 20 = 220 \)
SP of 1 egg = \( \text{₹ } 1.50 \)
Total SP = \( 220 \times 1.50 = \text{₹ } 330 \) (2 Marks)

(c) Profit or Loss %:
Since SP (\( \text{₹ } 330 \)) > CP (\( \text{₹ } 300 \)), there is a Profit.
Profit = \( 330 - 300 = \text{₹ } 30 \) (1 Mark)
\( \text{Profit \%} = \left( \frac{30}{300} \right) \times 100 = 10\% \) (1 Mark)
Ans: (a) ₹ 300, (b) ₹ 330, (c) 10% Profit
Q13. Buys 2 fans for \( \text{₹ } 1200 \) each. Sells one at \( 10\% \) profit, other at \( 5\% \) loss. Find (a) SP1 (b) SP2 (c) Overall Profit/Loss %.
[5 M]
Solution:
(a) Selling price of First Fan:
CP1 = \( \text{₹ } 1200 \), Profit = \( 10\% \)
Profit amount = \( 10\% \) of \( 1200 = \text{₹ } 120 \)
SP1 = \( 1200 + 120 = \text{₹ } 1320 \) (1.5 Marks)

(b) Selling price of Second Fan:
CP2 = \( \text{₹ } 1200 \), Loss = \( 5\% \)
Loss amount = \( 5\% \) of \( 1200 = \text{₹ } 60 \)
SP2 = \( 1200 - 60 = \text{₹ } 1140 \) (1.5 Marks)

(c) Overall Transaction:
Total CP = CP1 + CP2 = \( 1200 + 1200 = \text{₹ } 2400 \) (0.5 Mark)
Total SP = SP1 + SP2 = \( 1320 + 1140 = \text{₹ } 2460 \) (0.5 Mark)
Overall Profit = \( 2460 - 2400 = \text{₹ } 60 \)
\( \text{Overall Profit \%} = \left( \frac{60}{2400} \right) \times 100 = 2.5\% \) (1 Mark)
Ans: (a) ₹ 1320, (b) ₹ 1140, (c) 2.5% Profit
