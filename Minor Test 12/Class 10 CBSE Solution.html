SECTION A

Q1. If \(\sin \theta = \frac{3}{5}\), calculate the value of \((\tan \theta + \sec \theta)\).
[2 Marks]
Solution:

Given, \(\sin \theta = \frac{\text{Perpendicular (P)}}{\text{Hypotenuse (H)}} = \frac{3}{5}\).

Let \(P = 3k\) and \(H = 5k\). Using Pythagoras Theorem (\(H^2 = P^2 + B^2\)):

\[ (5k)^2 = (3k)^2 + B^2 \implies B^2 = 25k^2 - 9k^2 = 16k^2 \implies B = 4k \]

Now, \(\tan \theta = \frac{P}{B} = \frac{3k}{4k} = \frac{3}{4}\) and \(\sec \theta = \frac{H}{B} = \frac{5k}{4k} = \frac{5}{4}\).

Therefore, \(\tan \theta + \sec \theta = \frac{3}{4} + \frac{5}{4} = \frac{8}{4} = 2\).

Answer: 2
Q2. Evaluate: \( 2 \tan^2 45^\circ + \cos^2 30^\circ - \sin^2 60^\circ \)
[2 Marks]
Solution:

We know the standard trigonometric values:

  • \(\tan 45^\circ = 1\)
  • \(\cos 30^\circ = \frac{\sqrt{3}}{2}\)
  • \(\sin 60^\circ = \frac{\sqrt{3}}{2}\)

Substituting these values into the expression:

\[ = 2(1)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 - \left(\frac{\sqrt{3}}{2}\right)^2 \]
\[ = 2(1) + \frac{3}{4} - \frac{3}{4} = 2 + 0 = 2 \]
Answer: 2
Q3. Prove that: \((1 - \sin^2 A)\sec^2 A = 1\)
[2 Marks]
Solution:

Taking the Left Hand Side (LHS):

\[ \text{LHS} = (1 - \sin^2 A)\sec^2 A \]

Using the fundamental trigonometric identity: \(\sin^2 A + \cos^2 A = 1 \implies 1 - \sin^2 A = \cos^2 A\).

\[ \text{LHS} = (\cos^2 A) \cdot \sec^2 A \]

Since \(\sec A = \frac{1}{\cos A}\), we have \(\sec^2 A = \frac{1}{\cos^2 A}\).

\[ \text{LHS} = \cos^2 A \times \frac{1}{\cos^2 A} = 1 \]

\(\text{LHS} = \text{RHS}\). Hence Proved.

Q4. Given \(15 \cot A = 8\), find the value of \(\sin A\).
[2 Marks]
Solution:

Given, \(15 \cot A = 8 \implies \cot A = \frac{8}{15}\).

We know \(\cot A = \frac{\text{Base (B)}}{\text{Perpendicular (P)}}\). Let \(B = 8k\) and \(P = 15k\).

Using Pythagoras Theorem to find Hypotenuse (H):

\[ H^2 = P^2 + B^2 \implies H^2 = (15k)^2 + (8k)^2 = 225k^2 + 64k^2 = 289k^2 \]
\[ H = \sqrt{289k^2} = 17k \]

Now, \(\sin A = \frac{P}{H} = \frac{15k}{17k} = \frac{15}{17}\).

Answer: 15/17
Q5. Evaluate: \( \frac{2 \tan 30^\circ}{1 + \tan^2 30^\circ} \)
[2 Marks]
Solution:

Substitute the value of \(\tan 30^\circ = \frac{1}{\sqrt{3}}\):

\[ = \frac{2 \left( \frac{1}{\sqrt{3}} \right)}{1 + \left( \frac{1}{\sqrt{3}} \right)^2} \]
\[ = \frac{ \frac{2}{\sqrt{3}} }{1 + \frac{1}{3}} = \frac{ \frac{2}{\sqrt{3}} }{ \frac{4}{3} } \]
\[ = \frac{2}{\sqrt{3}} \times \frac{3}{4} = \frac{6}{4\sqrt{3}} = \frac{3}{2\sqrt{3}} \]

Rationalizing the denominator:

\[ = \frac{3\sqrt{3}}{2 \times 3} = \frac{\sqrt{3}}{2} \]

(Note: This is also equal to \(\sin 60^\circ\)).

Answer: \(\frac{\sqrt{3}}{2}\)

SECTION B

Q6. Prove that: \( \frac{\cos A}{1 + \sin A} + \frac{1 + \sin A}{\cos A} = 2 \sec A \)
[3 Marks]
Solution:

Taking the Left Hand Side (LHS) and finding the common denominator:

\[ \text{LHS} = \frac{\cos A \cdot \cos A + (1 + \sin A)(1 + \sin A)}{(1 + \sin A)\cos A} \]
\[ \text{LHS} = \frac{\cos^2 A + (1 + \sin A)^2}{(1 + \sin A)\cos A} \]

Expanding \((1 + \sin A)^2 = 1 + \sin^2 A + 2\sin A\):

\[ \text{LHS} = \frac{\cos^2 A + 1 + \sin^2 A + 2\sin A}{(1 + \sin A)\cos A} \]

Since \(\cos^2 A + \sin^2 A = 1\):

\[ \text{LHS} = \frac{1 + 1 + 2\sin A}{(1 + \sin A)\cos A} = \frac{2 + 2\sin A}{(1 + \sin A)\cos A} \]

Taking 2 common from the numerator:

\[ \text{LHS} = \frac{2(1 + \sin A)}{(1 + \sin A)\cos A} = \frac{2}{\cos A} = 2 \sec A \]

\(\text{LHS} = \text{RHS}\). Hence Proved.

Q7. Prove that: \( (\sin A + \text{cosec } A)^2 + (\cos A + \sec A)^2 = 7 + \tan^2 A + \cot^2 A \)
[3 Marks]
Solution:

Expand both squared binomials on the LHS using \((x+y)^2 = x^2+y^2+2xy\):

\[ \text{LHS} = (\sin^2 A + \text{cosec}^2 A + 2\sin A \text{cosec } A) + (\cos^2 A + \sec^2 A + 2\cos A \sec A) \]

Since \(\sin A \cdot \text{cosec } A = 1\) and \(\cos A \cdot \sec A = 1\):

\[ \text{LHS} = \sin^2 A + \text{cosec}^2 A + 2(1) + \cos^2 A + \sec^2 A + 2(1) \]

Rearranging the terms:

\[ \text{LHS} = (\sin^2 A + \cos^2 A) + \text{cosec}^2 A + \sec^2 A + 4 \]

We know \(\sin^2 A + \cos^2 A = 1\). Also, use identities \(\text{cosec}^2 A = 1 + \cot^2 A\) and \(\sec^2 A = 1 + \tan^2 A\):

\[ \text{LHS} = 1 + (1 + \cot^2 A) + (1 + \tan^2 A) + 4 \]
\[ \text{LHS} = 1 + 1 + 1 + 4 + \tan^2 A + \cot^2 A = 7 + \tan^2 A + \cot^2 A \]

\(\text{LHS} = \text{RHS}\). Hence Proved.

Q8. In \(\triangle PQR\), right-angled at \(Q\), \(PR + QR = 25\) cm and \(PQ = 5\) cm. Determine \(\sin P, \cos P, \tan P\).
[3 Marks]
Solution:

Given \(PQ = 5\) cm (Base for angle P), and \(PR + QR = 25 \implies PR = 25 - QR\).

Applying Pythagoras Theorem in \(\triangle PQR\): \(PR^2 = PQ^2 + QR^2\)

\[ (25 - QR)^2 = (5)^2 + QR^2 \]
\[ 625 - 50QR + QR^2 = 25 + QR^2 \]

Canceling \(QR^2\) from both sides:

\[ 625 - 25 = 50QR \implies 600 = 50QR \implies QR = 12 \text{ cm} \]

Now, calculate Hypotenuse \(PR = 25 - 12 = 13 \text{ cm}\).

With respect to angle P: Perpendicular (P) = \(QR = 12\), Base (B) = \(PQ = 5\), Hypotenuse (H) = \(PR = 13\).

\[ \sin P = \frac{P}{H} = \frac{12}{13} \]
\[ \cos P = \frac{B}{H} = \frac{5}{13} \]
\[ \tan P = \frac{P}{B} = \frac{12}{5} \]
\(\sin P = \frac{12}{13}\), \(\cos P = \frac{5}{13}\), \(\tan P = \frac{12}{5}\)
Q9. Prove that: \( \sqrt{\frac{1 + \sin A}{1 - \sin A}} = \sec A + \tan A \)
[3 Marks]
Solution:

Take the LHS and rationalize the expression inside the square root by multiplying numerator and denominator by \((1 + \sin A)\):

\[ \text{LHS} = \sqrt{\frac{(1 + \sin A)}{(1 - \sin A)} \times \frac{(1 + \sin A)}{(1 + \sin A)}} \]
\[ \text{LHS} = \sqrt{\frac{(1 + \sin A)^2}{1^2 - \sin^2 A}} \]

Using the identity \(1 - \sin^2 A = \cos^2 A\):

\[ \text{LHS} = \sqrt{\frac{(1 + \sin A)^2}{\cos^2 A}} = \frac{1 + \sin A}{\cos A} \]

Separating the denominator:

\[ \text{LHS} = \frac{1}{\cos A} + \frac{\sin A}{\cos A} = \sec A + \tan A \]

\(\text{LHS} = \text{RHS}\). Hence Proved.

Q10. Prove that: \( \frac{\sin \theta - 2\sin^3 \theta}{2\cos^3 \theta - \cos \theta} = \tan \theta \)
[3 Marks]
Solution:

Taking LHS, factor out \(\sin \theta\) from numerator and \(\cos \theta\) from denominator:

\[ \text{LHS} = \frac{\sin \theta (1 - 2\sin^2 \theta)}{\cos \theta (2\cos^2 \theta - 1)} \]

Use the identity \(\sin^2 \theta = 1 - \cos^2 \theta\) in the numerator:

\[ \text{LHS} = \frac{\sin \theta [1 - 2(1 - \cos^2 \theta)]}{\cos \theta (2\cos^2 \theta - 1)} \]
\[ \text{LHS} = \frac{\sin \theta [1 - 2 + 2\cos^2 \theta]}{\cos \theta (2\cos^2 \theta - 1)} \]
\[ \text{LHS} = \frac{\sin \theta (2\cos^2 \theta - 1)}{\cos \theta (2\cos^2 \theta - 1)} \]

Cancel out the common term \((2\cos^2 \theta - 1)\) from numerator and denominator:

\[ \text{LHS} = \frac{\sin \theta}{\cos \theta} = \tan \theta \]

\(\text{LHS} = \text{RHS}\). Hence Proved.

SECTION C

Q11. Prove that: \( \frac{\tan \theta}{1 - \cot \theta} + \frac{\cot \theta}{1 - \tan \theta} = 1 + \sec \theta \text{ cosec } \theta \)
[5 Marks]
Solution:

Convert all terms in LHS to \(\sin \theta\) and \(\cos \theta\):

\[ \text{LHS} = \frac{\frac{\sin \theta}{\cos \theta}}{1 - \frac{\cos \theta}{\sin \theta}} + \frac{\frac{\cos \theta}{\sin \theta}}{1 - \frac{\sin \theta}{\cos \theta}} \]

Simplify denominators by taking LCM:

\[ \text{LHS} = \frac{\frac{\sin \theta}{\cos \theta}}{\frac{\sin \theta - \cos \theta}{\sin \theta}} + \frac{\frac{\cos \theta}{\sin \theta}}{\frac{\cos \theta - \sin \theta}{\cos \theta}} \]
\[ \text{LHS} = \frac{\sin^2 \theta}{\cos \theta(\sin \theta - \cos \theta)} + \frac{\cos^2 \theta}{\sin \theta(\cos \theta - \sin \theta)} \]

Change the sign of the second term to make the brackets identical: \((\cos \theta - \sin \theta) = -(\sin \theta - \cos \theta)\):

\[ \text{LHS} = \frac{\sin^2 \theta}{\cos \theta(\sin \theta - \cos \theta)} - \frac{\cos^2 \theta}{\sin \theta(\sin \theta - \cos \theta)} \]

Take LCM of denominators: \(\sin \theta \cos \theta (\sin \theta - \cos \theta)\)

\[ \text{LHS} = \frac{\sin^3 \theta - \cos^3 \theta}{\sin \theta \cos \theta (\sin \theta - \cos \theta)} \]

Use identity \(a^3 - b^3 = (a - b)(a^2 + b^2 + ab)\):

\[ \text{LHS} = \frac{(\sin \theta - \cos \theta)(\sin^2 \theta + \cos^2 \theta + \sin \theta \cos \theta)}{\sin \theta \cos \theta (\sin \theta - \cos \theta)} \]

Cancel \((\sin \theta - \cos \theta)\) and apply \(\sin^2 \theta + \cos^2 \theta = 1\):

\[ \text{LHS} = \frac{1 + \sin \theta \cos \theta}{\sin \theta \cos \theta} = \frac{1}{\sin \theta \cos \theta} + \frac{\sin \theta \cos \theta}{\sin \theta \cos \theta} \]
\[ \text{LHS} = \text{cosec } \theta \sec \theta + 1 = 1 + \sec \theta \text{ cosec } \theta \]

\(\text{LHS} = \text{RHS}\). Hence Proved.

Q12. Prove: \( \frac{\cos A - \sin A + 1}{\cos A + \sin A - 1} = \text{cosec } A + \cot A \) using \(\text{cosec}^2 A = 1 + \cot^2 A\)
[5 Marks]
Solution:

Divide numerator and denominator of LHS by \(\sin A\):

\[ \text{LHS} = \frac{\frac{\cos A}{\sin A} - \frac{\sin A}{\sin A} + \frac{1}{\sin A}}{\frac{\cos A}{\sin A} + \frac{\sin A}{\sin A} - \frac{1}{\sin A}} \]
\[ \text{LHS} = \frac{\cot A - 1 + \text{cosec } A}{\cot A + 1 - \text{cosec } A} \]

Rearrange the numerator to group \(\cot A\) and \(\text{cosec } A\):

\[ \text{LHS} = \frac{(\cot A + \text{cosec } A) - 1}{\cot A - \text{cosec } A + 1} \]

Substitute \(1 = \text{cosec}^2 A - \cot^2 A\) in the numerator only:

\[ \text{LHS} = \frac{(\text{cosec } A + \cot A) - (\text{cosec}^2 A - \cot^2 A)}{\cot A - \text{cosec } A + 1} \]

Factorize \((\text{cosec}^2 A - \cot^2 A)\) as \((\text{cosec } A - \cot A)(\text{cosec } A + \cot A)\):

\[ \text{LHS} = \frac{(\text{cosec } A + \cot A) - [(\text{cosec } A - \cot A)(\text{cosec } A + \cot A)]}{\cot A - \text{cosec } A + 1} \]

Take \((\text{cosec } A + \cot A)\) common from the numerator terms:

\[ \text{LHS} = \frac{(\text{cosec } A + \cot A)[1 - (\text{cosec } A - \cot A)]}{\cot A - \text{cosec } A + 1} \]
\[ \text{LHS} = \frac{(\text{cosec } A + \cot A)(1 - \text{cosec } A + \cot A)}{\cot A - \text{cosec } A + 1} \]

The term \((1 - \text{cosec } A + \cot A)\) is identical in both numerator and denominator. Canceling them out:

\[ \text{LHS} = \text{cosec } A + \cot A \]

\(\text{LHS} = \text{RHS}\). Hence Proved.

Q13. Evaluate: \( \frac{\sin 30^\circ + \tan 45^\circ - \text{cosec } 60^\circ}{\sec 30^\circ + \cos 60^\circ + \cot 45^\circ} \)
[5 Marks]
Solution:

Write standard values for all trigonometric ratios:

  • \(\sin 30^\circ = 1/2\), \(\tan 45^\circ = 1\), \(\text{cosec } 60^\circ = 2/\sqrt{3}\)
  • \(\sec 30^\circ = 2/\sqrt{3}\), \(\cos 60^\circ = 1/2\), \(\cot 45^\circ = 1\)

Substituting the values into the expression:

\[ = \frac{\frac{1}{2} + 1 - \frac{2}{\sqrt{3}}}{\frac{2}{\sqrt{3}} + \frac{1}{2} + 1} \]

Simplify numerator and denominator separately:

\[ \text{Numerator} = \frac{3}{2} - \frac{2}{\sqrt{3}} = \frac{3\sqrt{3} - 4}{2\sqrt{3}} \]
\[ \text{Denominator} = \frac{2}{\sqrt{3}} + \frac{3}{2} = \frac{4 + 3\sqrt{3}}{2\sqrt{3}} \]

Now, divide numerator by denominator (the \(2\sqrt{3}\) cancels out):

\[ = \frac{3\sqrt{3} - 4}{3\sqrt{3} + 4} \]

Rationalize the denominator by multiplying by its conjugate \((3\sqrt{3} - 4)\):

\[ = \frac{(3\sqrt{3} - 4)(3\sqrt{3} - 4)}{(3\sqrt{3} + 4)(3\sqrt{3} - 4)} \]
\[ = \frac{(3\sqrt{3})^2 + 4^2 - 2(3\sqrt{3})(4)}{(3\sqrt{3})^2 - 4^2} \]
\[ = \frac{27 + 16 - 24\sqrt{3}}{27 - 16} \]
\[ = \frac{43 - 24\sqrt{3}}{11} \]
Answer: \(\frac{43 - 24\sqrt{3}}{11}\)
Q14. If \(\sec \theta + \tan \theta = p\), then show that: \( \frac{p^2 - 1}{p^2 + 1} = \sin \theta \)
[5 Marks]
Solution:

We are given \(\sec \theta + \tan \theta = p\) ---- (Equation 1)

We know the identity: \(\sec^2 \theta - \tan^2 \theta = 1\).

Factoring it: \((\sec \theta - \tan \theta)(\sec \theta + \tan \theta) = 1\)

Substituting \(p\) from Equation 1:

\[ (\sec \theta - \tan \theta) \cdot p = 1 \implies \sec \theta - \tan \theta = \frac{1}{p} \text{ ---- (Equation 2)} \]

Step A: Find \(\sec \theta\) by adding Eq 1 and Eq 2:

\[ (\sec \theta + \tan \theta) + (\sec \theta - \tan \theta) = p + \frac{1}{p} \]
\[ 2\sec \theta = \frac{p^2 + 1}{p} \implies \sec \theta = \frac{p^2 + 1}{2p} \]

Step B: Find \(\tan \theta\) by subtracting Eq 2 from Eq 1:

\[ (\sec \theta + \tan \theta) - (\sec \theta - \tan \theta) = p - \frac{1}{p} \]
\[ 2\tan \theta = \frac{p^2 - 1}{p} \implies \tan \theta = \frac{p^2 - 1}{2p} \]

Step C: Find \(\sin \theta\)

We know that \(\sin \theta = \frac{\sin \theta / \cos \theta}{1 / \cos \theta} = \frac{\tan \theta}{\sec \theta}\).

Substitute values of \(\tan \theta\) and \(\sec \theta\):

\[ \sin \theta = \frac{ \frac{p^2 - 1}{2p} }{ \frac{p^2 + 1}{2p} } = \frac{p^2 - 1}{p^2 + 1} \]

Hence Proved.

Q15. Prove that: \( (\text{cosec } \theta - \cot \theta)^2 = \frac{1 - \cos \theta}{1 + \cos \theta} \)
[5 Marks]
Solution:

Take the LHS and convert \(\text{cosec } \theta\) and \(\cot \theta\) into \(\sin \theta\) and \(\cos \theta\):

\[ \text{LHS} = (\text{cosec } \theta - \cot \theta)^2 = \left( \frac{1}{\sin \theta} - \frac{\cos \theta}{\sin \theta} \right)^2 \]

Combining the fractions inside the bracket:

\[ \text{LHS} = \left( \frac{1 - \cos \theta}{\sin \theta} \right)^2 \]

Applying the square to numerator and denominator:

\[ \text{LHS} = \frac{(1 - \cos \theta)^2}{\sin^2 \theta} \]

Using the fundamental identity \(\sin^2 \theta = 1 - \cos^2 \theta\):

\[ \text{LHS} = \frac{(1 - \cos \theta)^2}{1 - \cos^2 \theta} \]

Factorize the denominator using \(a^2 - b^2 = (a-b)(a+b)\) where \(a=1, b=\cos \theta\):

\[ \text{LHS} = \frac{(1 - \cos \theta)(1 - \cos \theta)}{(1 - \cos \theta)(1 + \cos \theta)} \]

Cancel out the common term \((1 - \cos \theta)\):

\[ \text{LHS} = \frac{1 - \cos \theta}{1 + \cos \theta} \]

\(\text{LHS} = \text{RHS}\). Hence Proved.
