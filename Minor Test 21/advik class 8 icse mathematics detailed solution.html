SECTION A SOLUTIONS (10 MARKS)

Q1. What percentage is $15$ of $75$?
[2 Marks]
Correct Option: (B) $20\%$
Step-by-Step Solution:
Required Percentage formula:
$$\text{Percentage} = \left(\frac{\text{Given Value}}{\text{Total Value}} \times 100\right)\%$$ $$\text{Percentage} = \left(\frac{15}{75} \times 100\right)\% = \left(\frac{1}{5} \times 100\right)\% = \mathbf{20\%}$$
Q2. Factorise completely: $16x^2 - 81y^2$.
[2 Marks]
Correct Option: (A) $(4x - 9y)(4x + 9y)$
Step-by-Step Solution:
Express both terms as perfect squares:
$$16x^2 - 81y^2 = (4x)^2 - (9y)^2$$
Applying identity $A^2 - B^2 = (A - B)(A + B)$ where $A = 4x$ and $B = 9y$:
$$= \mathbf{(4x - 9y)(4x + 9y)}$$
Q3. A student scores $360$ marks out of $450$ marks. Calculate percentage score.
[2 Marks]
Correct Option: (B) $80\%$
Step-by-Step Solution:
Marks obtained $= 360$, Maximum marks $= 450$.
$$\text{Percentage Score} = \frac{360}{450} \times 100 = \frac{4}{5} \times 100 = \mathbf{80\%}$$
Q4. Original price increases from $\text{₹}800$ to $\text{₹}960$. Calculate percentage increase.
[2 Marks]
Percentage Increase $= 20\%$
Step-by-Step Solution:
Original Price $= \text{₹}800$, New Price $= \text{₹}960$.
$$\text{Increase in Price} = 960 - 800 = \text{₹}160$$ $$\text{Percentage Increase} = \frac{\text{Increase}}{\text{Original Price}} \times 100 = \frac{160}{800} \times 100 = \mathbf{20\%}$$
Q5. Factorise: $x^2 - 7x + 12$.
[2 Marks]
Factors $= (x - 3)(x - 4)$
Step-by-Step Solution:
Find two numbers whose product is $+12$ and sum is $-7$. The numbers are $-3$ and $-4$.
$$x^2 - 7x + 12 = x^2 - 3x - 4x + 12$$ $$= x(x - 3) - 4(x - 3) = \mathbf{(x - 3)(x - 4)}$$

SECTION B SOLUTIONS (15 MARKS)

Q6. Factorise by splitting middle term: $2a^2 + 7a + 3$.
[3 Marks]
Step-by-Step Solution:
Product $= 2 \times 3 = 6$, Sum $= 7$. Required numbers are $6$ and $1$.
$$2a^2 + 7a + 3 = 2a^2 + 6a + a + 3$$ $$= 2a(a + 3) + 1(a + 3)$$ $$= \mathbf{(2a + 1)(a + 3)}$$
Q7. Monthly salary $= \text{₹}45,000$. Expenditures: Rent $20\%$, Household $40\%$, Education $15\%$. Find monthly savings.
[3 Marks]
Step-by-Step Solution:
Total Expenditure percentage:
$$\text{Total Expenditure \%} = 20\% + 40\% + 15\% = 75\%$$ $$\text{Savings \%} = 100\% - 75\% = 25\%$$ $$\text{Monthly Savings Amount} = 25\% \text{ of } 45,000 = \frac{25}{100} \times 45000 = \mathbf{\text{₹}11,250}$$
Q8. Factorise completely: $x^4 - 16y^4$.
[3 Marks]
Step-by-Step Solution:
Applying difference of squares identity repeatedly:
$$x^4 - 16y^4 = (x^2)^2 - (4y^2)^2 = (x^2 - 4y^2)(x^2 + 4y^2)$$ $$= (x^2 - (2y)^2)(x^2 + 4y^2)$$ $$= \mathbf{(x - 2y)(x + 2y)(x^2 + 4y^2)}$$
Q9. Price of sugar rises by $25\%$. Find percentage reduction in consumption to keep expenditure constant.
[3 Marks]
Step-by-Step Solution:
Let original price $= \text{₹}100$ per unit and original consumption $= 100$ units.
Original Expenditure $= 100 \times 100 = \text{₹}10,000$.
New Price $= 100 + 25\% \text{ of } 100 = \text{₹}125$.
To keep expenditure at $\text{₹}10,000$:
$$\text{New Consumption} = \frac{10000}{125} = 80 \text{ units}$$ $$\text{Reduction in Consumption} = 100 - 80 = 20 \text{ units}$$ $$\text{Percentage Reduction} = \left(\frac{20}{100} \times 100\right)\% = \mathbf{20\%}$$
Q10. Factorise: $a^2 - b^2 - 2bc - c^2$.
[3 Marks]
Step-by-Step Solution:
Group the last three terms by taking out negative sign:
$$a^2 - b^2 - 2bc - c^2 = a^2 - (b^2 + 2bc + c^2)$$ $$= a^2 - (b + c)^2$$
Applying $A^2 - B^2 = (A - B)(A + B)$ where $A = a$ and $B = (b + c)$:
$$= [a - (b + c)][a + (b + c)] = \mathbf{(a - b - c)(a + b + c)}$$

SECTION C SOLUTIONS (15 MARKS)

Q11. $85\%$ passed examination, $45$ failed.
(a) Total candidates appeared.
(b) Number of girls if $60\%$ were boys.
[5 Marks]
Part (a): Finding Total Candidates [3 Marks]
Pass percentage $= 85\% \implies$ Fail percentage $= 100\% - 85\% = 15\%$.
Let total candidates be $N$.
$$15\% \text{ of } N = 45 \implies \frac{15}{100} \times N = 45$$ $$N = \frac{45 \times 100}{15} = 3 \times 100 = \mathbf{300 \text{ candidates}}$$
Part (b): Finding Number of Girls [2 Marks]
Percentage of boys $= 60\% \implies$ Percentage of girls $= 100\% - 60\% = 40\%$.
$$\text{Number of Girls} = 40\% \text{ of } 300 = \frac{40}{100} \times 300 = \mathbf{120 \text{ girls}}$$
Q12. Factorise: (a) $x^2 + \frac{1}{x^2} - 2 - 5x + \frac{5}{x}$   (b) $8x^3 + 27y^3$.
[5 Marks]
Part (a) Solution [2.5 Marks]:
Observe that $x^2 + \frac{1}{x^2} - 2 = \left(x - \frac{1}{x}\right)^2$.
$$x^2 + \frac{1}{x^2} - 2 - 5x + \frac{5}{x} = \left(x - \frac{1}{x}\right)^2 - 5\left(x - \frac{1}{x}\right)$$
Factoring out common term $\left(x - \frac{1}{x}\right)$:
$$= \mathbf{\left(x - \frac{1}{x}\right)\left(x - \frac{1}{x} - 5\right)}$$
Part (b) Solution [2.5 Marks]:
Express as sum of cubes $A^3 + B^3 = (A + B)(A^2 - AB + B^2)$:
$$8x^3 + 27y^3 = (2x)^3 + (3y)^3$$ $$= (2x + 3y)((2x)^2 - (2x)(3y) + (3y)^2)$$ $$= \mathbf{(2x + 3y)(4x^2 - 6xy + 9y^2)}$$
Q13. [HOTS] Factory batch production, quality control, polynomial factorisation, and profit/loss calculation.
[5 Marks]
Part (a): Total Components Produced [2.5 Marks]
Let total production $= T$.
Defective components $= 8\% \text{ of } T = 0.08 T$.
Non-defective components $= (100 - 8)\% = 92\% \text{ of } T = 0.92 T$.
Domestic sales $= 75\% \text{ of } 0.92 T = 0.69 T$.
Exported components $= 0.92 T - 0.69 T = 0.23 T = 23\% \text{ of } T$.
$$0.23 T = 2,070 \implies T = \frac{2070}{0.23} = \mathbf{9,000 \text{ components}}$$
Part (b): Polynomial Factorisation [1.5 Marks]
Factorise $1000x^3 - 125$:
$$1000x^3 - 125 = (10x)^3 - (5)^3$$ $$= (10x - 5)((10x)^2 + (10x)(5) + 5^2)$$ $$= (10x - 5)(100x^2 + 50x + 25) = \mathbf{125(2x - 1)(4x^2 + 2x + 1)}$$
Part (c): Net Profit/Loss Percentage Calculation [1 Mark]
Total components in batch $= 9,000$.
Defective items $= 8\% \text{ of } 9000 = 720$ items.
Exported items $= 2,070$ items.
Let cost price per item $= C$.
Total Cost Price for these two combined batches $= (720 + 2070) \times C = 2790 C$.
Selling Price of Defective items ($60\%$ discount $\implies 40\%$ of C) $= 720 \times 0.40 C = 288 C$.
Selling Price of Exported items ($20\%$ profit $\implies 120\%$ of C) $= 2070 \times 1.20 C = 2484 C$.
Total Selling Price $= 288 C + 2484 C = 2772 C$.
Net Loss $= 2790 C - 2772 C = 18 C$.
$$\text{Net Loss \%} = \frac{18 C}{2790 C} \times 100 = \frac{1800}{2790}\% = \mathbf{0.645\% \text{ loss}}$$
