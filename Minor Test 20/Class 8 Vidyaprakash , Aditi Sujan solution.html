Q1. State the formula for Amount ($A$) and Compound Interest ($CI$) compounded (a) annually and (b) half-yearly.
[2 Marks]
✔ Answer: (a) $A = P\left(1 + \frac{r}{100}\right)^n$ | (b) $A = P\left(1 + \frac{r}{200}\right)^{2n}$; $CI = A - P$.

(a) Interest Compounded Annually:

$$A = P \left(1 + \frac{r}{100}\right)^n \quad \text{and} \quad CI = A - P$$
(1 Mark)

(b) Interest Compounded Half-Yearly (Semi-Annually):

$$A = P \left(1 + \frac{r/2}{100}\right)^{2n} = P \left(1 + \frac{r}{200}\right)^{2n} \quad \text{and} \quad CI = A - P$$
(1 Mark)
Q2. Compound interest on $\text{₹ } 5,000$ for $2$ years at $10\%$ per annum compounded annually.
[2 Marks]
✔ Correct Answer: Amount $A = \text{₹ } 6,050$, Compound Interest $CI = \text{₹ } 1,050$.

Given: Principal ($P$) = $\text{₹ } 5,000$, Rate ($r$) = $10\%$ p.a., Time ($n$) = $2$ years.

$$A = P \left(1 + \frac{r}{100}\right)^n = 5000 \left(1 + \frac{10}{100}\right)^2 = 5000 \left(\frac{11}{10}\right)^2$$ $$A = 5000 \times \frac{121}{100} = 50 \times 121 = \text{₹ } 6,050$$
(1 Mark for Amount calculation)
$$CI = A - P = 6050 - 5000 = \mathbf{\text{₹ } 1,050}$$
(1 Mark for CI calculation)
Q3. Difference between $SI$ and $CI$ on $\text{₹ } 8,000$ for $1$ year at $5\%$ p.a. compounded half-yearly.
[2 Marks]
✔ Correct Answer: Difference = $CI - SI = 405 - 400 = \text{₹ } 5$.

1. Simple Interest ($SI$):

$$SI = \frac{P \times r \times t}{100} = \frac{8000 \times 5 \times 1}{100} = \text{₹ } 400$$

2. Compound Interest ($CI$) Compounded Half-yearly:

For $1$ year, number of half-years ($2n$) = $2$. Adjusted rate ($r'$) = $\frac{5}{2} = 2.5\%$.

$$A = 8000 \left(1 + \frac{2.5}{100}\right)^2 = 8000 \left(\frac{41}{40}\right)^2 = 8000 \times \frac{1681}{1600} = 5 \times 1681 = \text{₹ } 8,405$$ $$CI = A - P = 8405 - 8000 = \text{₹ } 405$$

3. Difference:

$$\text{Difference} = CI - SI = 405 - 400 = \mathbf{\text{₹ } 5}$$
(1 Mark for SI & CI computation + 1 Mark for difference)
Q4. Compound Amount on $\text{₹ } 10,000$ at $10\%$ p.a. for $1$ year compounded semi-annually.
[2 Marks]
✔ Correct Answer: Final Amount $A = \text{₹ } 11,025$.

Given: $P = \text{₹ } 10,000$, Rate per half-year = $\frac{10}{2}\% = 5\%$, Time period ($2n$) = $2$ half-years.

$$A = P \left(1 + \frac{r}{200}\right)^{2n} = 10000 \left(1 + \frac{5}{100}\right)^2$$ $$A = 10000 \times \left(\frac{21}{20}\right)^2 = 10000 \times \frac{441}{400} = 25 \times 441 = \mathbf{\text{₹ } 11,025}$$
(2 Marks)
Q5. Depreciated value of a machine costing $\text{₹ } 25,000$ at $10\%$ p.a. after $1$ year.
[2 Marks]
✔ Correct Answer: Value after 1 year = $\text{₹ } 22,500$.

Depreciation Formula: $V = P \left(1 - \frac{r}{100}\right)^n$

$$V = 25000 \left(1 - \frac{10}{100}\right)^1 = 25000 \times \frac{9}{10} = \mathbf{\text{₹ } 22,500}$$
(2 Marks)
SECTION B — SOLUTIONS & MARKING SCHEME (15 MARKS)
Q6. Find principal if difference between $CI$ and $SI$ for $2$ years at $10\%$ p.a. is $\text{₹ } 150$.
[3 Marks]
✔ Correct Answer: Principal ($P$) = $\text{₹ } 15,000$.

Let the principal sum be $P$.

Simple Interest ($SI$):

$$SI = \frac{P \times 10 \times 2}{100} = \frac{20P}{100} = 0.20 P$$

Compound Interest ($CI$):

$$A = P \left(1 + \frac{10}{100}\right)^2 = P \left(\frac{11}{10}\right)^2 = 1.21 P$$ $$CI = A - P = 1.21 P - P = 0.21 P$$

Given Difference: $CI - SI = \text{₹ } 150$

$$0.21 P - 0.20 P = 150 \implies 0.01 P = 150$$ $$P = \frac{150}{0.01} = \mathbf{\text{₹ } 15,000}$$
(1 Mark for SI & CI expressions + 1 Mark for equation setup + 1 Mark for final value)
Q7. $CI$ on $\text{₹ } 12,500$ at $12\%$ p.a. for $1.5$ years compounded half-yearly.
[3 Marks]
✔ Correct Answer: Amount $A = \text{₹ } 14,887.70$, $CI = \text{₹ } 2,387.70$.

Given: $P = \text{₹ } 12,500$, Annual Rate ($r$) = $12\% \implies$ Half-yearly rate ($r'$) = $6\%$.

Time period ($n$) = $1.5$ years $\implies$ Number of half-years ($2n$) = $3$.

$$A = P \left(1 + \frac{r'}{100}\right)^{2n} = 12500 \left(1 + \frac{6}{100}\right)^3 = 12500 \left(\frac{53}{50}\right)^3$$ $$A = 12500 \times \frac{1,48,877}{1,25,000} = \frac{1,48,877}{10} = \mathbf{\text{₹ } 14,887.70}$$
(2 Marks for Amount)
$$CI = A - P = 14887.70 - 12500 = \mathbf{\text{₹ } 2,387.70}$$
(1 Mark for CI)
Q8. Amount and $CI$ on $\text{₹ } 20,000$ with successive annual interest rates of $8\%$ and $10\%$.
[3 Marks]
✔ Correct Answer: Amount = $\text{₹ } 23,760$, $CI = \text{₹ } 3,760$.

For successive annual rates $r_1 = 8\%$ and $r_2 = 10\%$, formula for Amount:

$$A = P \left(1 + \frac{r_1}{100}\right) \left(1 + \frac{r_2}{100}\right)$$ $$A = 20000 \left(1 + \frac{8}{100}\right) \left(1 + \frac{10}{100}\right) = 20000 \times \frac{108}{100} \times \frac{110}{100}$$ $$A = 20000 \times 1.08 \times 1.10 = \mathbf{\text{₹ } 23,760}$$
(2 Marks for Amount)
$$CI = A - P = 23760 - 20000 = \mathbf{\text{₹ } 3,760}$$
(1 Mark for CI)
Q9. Value of a motorcycle costing $\text{₹ } 80,000$ after $2$ years at $10\%$ p.a. depreciation.
[3 Marks]
✔ Correct Answer: Depreciated Value = $\text{₹ } 64,800$.

Given: Initial Cost ($P$) = $\text{₹ } 80,000$, Depreciation rate ($r$) = $10\%$ p.a., Time ($n$) = $2$ years.

$$V = P \left(1 - \frac{r}{100}\right)^n = 80000 \left(1 - \frac{10}{100}\right)^2$$ $$V = 80000 \times \left(\frac{9}{10}\right)^2 = 80000 \times \frac{81}{100} = 800 \times 81 = \mathbf{\text{₹ } 64,800}$$
(3 Marks: 1 mark formula + 2 marks calculation)
Q10. Population of town in 2022 is $1,76,400$ growing at $5\%$ p.a. Find (a) Population in 2024, (b) Population in 2020.
[3 Marks]
✔ Correct Answer: (a) Population in 2024 = $1,94,481$ | (b) Population in 2020 = $1,60,000$.

(a) Population in 2024 ($2$ years later):

$$P_{2024} = P_{2022} \left(1 + \frac{5}{100}\right)^2 = 176400 \times \left(\frac{21}{20}\right)^2$$ $$P_{2024} = 176400 \times \frac{441}{400} = 441 \times 441 = \mathbf{1,94,481}$$
(1.5 Marks)

(b) Population in 2020 ($2$ years ago):

$$P_{2022} = P_{2020} \left(1 + \frac{5}{100}\right)^2 \implies 176400 = P_{2020} \times \frac{441}{400}$$ $$P_{2020} = 176400 \times \frac{400}{441} = 400 \times 400 = \mathbf{1,60,000}$$
(1.5 Marks)

Q11. (a) Rate percent if $\text{₹ } 4,000$ becomes $\text{₹ } 4,840$ in $2$ years. (b) Time for $\text{₹ } 8,000$ to become $\text{₹ } 9,261$ at $5\%$ p.a.
[5 Marks]
✔ Correct Answer: (a) Rate ($r$) = $10\%$ p.a. | (b) Time ($n$) = $3$ years.

Part (a): Find Rate Percent ($r$)

Given: $P = 4000$, $A = 4840$, $n = 2$ years.

$$A = P \left(1 + \frac{r}{100}\right)^2 \implies 4840 = 4000 \left(1 + \frac{r}{100}\right)^2$$ $$\frac{4840}{4000} = \left(1 + \frac{r}{100}\right)^2 \implies \frac{121}{100} = \left(1 + \frac{r}{100}\right)^2$$ $$\left(\frac{11}{10}\right)^2 = \left(1 + \frac{r}{100}\right)^2 \implies 1 + \frac{r}{100} = \frac{11}{10}$$ $$\frac{r}{100} = \frac{11}{10} - 1 = \frac{1}{10} \implies r = \mathbf{10\% \text{ p.a.}}$$
(2.5 Marks)

Part (b): Find Time Period ($n$)

Given: $P = 8000$, $A = 9261$, $r = 5\%$.

$$A = P \left(1 + \frac{r}{100}\right)^n \implies 9261 = 8000 \left(1 + \frac{5}{100}\right)^n$$ $$\frac{9261}{8000} = \left(\frac{21}{20}\right)^n \implies \left(\frac{21}{20}\right)^3 = \left(\frac{21}{20}\right)^n$$ $$\text{Comparing exponents: } n = \mathbf{3 \text{ years}}$$
(2.5 Marks)
Q12. Compare half-yearly vs annual compounding for $\text{₹ } 16,000$ at $10\%$ p.a. for $1.5$ years.
[5 Marks]
✔ Correct Answer: (a) Half-Yearly $CI = \text{₹ } 2,522$ | (b) Annual $CI = \text{₹ } 2,480$ | (c) Extra Gain = $\text{₹ } 42$.

Given: Principal ($P$) = $\text{₹ } 16,000$, Rate ($r$) = $10\%$ p.a., Time = $1 \frac{1}{2}$ years.

(a) Compounded Half-Yearly:

Rate per half-year ($r'$) = $5\%$, Number of half-years ($2n$) = $3$.

$$A_1 = 16000 \left(1 + \frac{5}{100}\right)^3 = 16000 \times \left(\frac{21}{20}\right)^3 = 16000 \times \frac{9261}{8000} = 2 \times 9261 = \text{₹ } 18,522$$ $$CI_1 = 18522 - 16000 = \mathbf{\text{₹ } 2,522}$$
(2.5 Marks)

(b) Compounded Annually for $1 \frac{1}{2}$ years:

Amount for $1^{\text{st}}$ full year: $A_1' = 16000 \left(1 + \frac{10}{100}\right) = \text{₹ } 17,600$.

Interest for remaining $\frac{1}{2}$ year on $\text{₹ } 17,600$: $SI = \frac{17600 \times 10 \times 1/2}{100} = \text{₹ } 880$.

Total Amount ($A_2$) = $17600 + 880 = \text{₹ } 18,480$.

$$CI_2 = 18480 - 16000 = \mathbf{\text{₹ } 2,480}$$
(2 Marks)

(c) Extra Gain:

$$\text{Extra Gain} = CI_1 - CI_2 = 2522 - 2480 = \mathbf{\text{₹ } 42}$$
(0.5 Mark)
Q13. A sum amounts to $\text{₹ } 12,100$ in $2$ years and $\text{₹ } 13,310$ in $3$ years. Find rate of interest and principal sum.
[5 Marks]
✔ Correct Answer: (a) Rate ($r$) = $10\%$ p.a. | (b) Principal Sum ($P$) = $\text{₹ } 10,000$.

(a) Find Rate of Interest ($r\%$):

Amount after 2 years ($A_2$) = $\text{₹ } 12,100$

Amount after 3 years ($A_3$) = $\text{₹ } 13,310$

The difference in amounts is the interest earned on $\text{₹ } 12,100$ for $1$ year.

$$\text{Interest for } 3^{\text{rd}} \text{ year} = 13310 - 12100 = \text{₹ } 1,210$$ $$r = \frac{\text{Interest} \times 100}{\text{Principal for year } 3 \times 1} = \frac{1210 \times 100}{12100 \times 1} = \mathbf{10\% \text{ p.a.}}$$
(2.5 Marks)

(b) Find Original Principal ($P$):

Using $A_2 = 12,100$, $r = 10\%$, and $n = 2$ years:

$$12100 = P \left(1 + \frac{10}{100}\right)^2 \implies 12100 = P \left(\frac{11}{10}\right)^2$$ $$12100 = P \times \frac{121}{100} \implies P = \frac{12100 \times 100}{121} = \mathbf{\text{₹ } 10,000}$$
(2.5 Marks)
