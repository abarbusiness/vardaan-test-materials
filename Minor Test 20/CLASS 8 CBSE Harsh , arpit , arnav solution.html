Q1. Write the additive inverse and multiplicative inverse of (a) $-\frac{7}{19}$, (b) $\frac{-5}{8} \times \frac{-3}{7}$.
[2 Marks]
✔ Answer: (a) Additive: $\frac{7}{19}$, Multiplicative: $-\frac{19}{7}$ | (b) Simplified: $\frac{15}{56}$; Additive: $-\frac{15}{56}$, Multiplicative: $\frac{56}{15}$.

(a) For $-\frac{7}{19}$:

$$\text{Additive Inverse} = -\left(-\frac{7}{19}\right) = \mathbf{\frac{7}{19}}$$ $$\text{Multiplicative Inverse (Reciprocal)} = \mathbf{-\frac{19}{7}}$$
(1 Mark)

(b) For $\frac{-5}{8} \times \frac{-3}{7} = \frac{15}{56}$:

$$\text{Additive Inverse} = \mathbf{-\frac{15}{56}}$$ $$\text{Multiplicative Inverse} = \mathbf{\frac{56}{15}}$$
(1 Mark)
Q2. Solve linear equation: $\frac{3x - 5}{2} = \frac{x + 7}{3}$.
[2 Marks]
✔ Correct Answer: $x = \mathbf{29}$.

Cross-multiplying both sides of the equation:

$$3(3x - 5) = 2(x + 7)$$ $$9x - 15 = 2x + 14$$
(1 Mark for cross-multiplication)

Transposing variable terms to LHS and constants to RHS:

$$9x - 2x = 14 + 15 \implies 7x = 29 \implies x = \mathbf{\frac{29}{7}} \text{ or } \mathbf{4.14}$$
(1 Mark for final value)
Q3. Two adjacent angles of a parallelogram are in ratio $2 : 3$. Find all four angles.
[2 Marks]
✔ Correct Answer: Angles are $72^\circ, 108^\circ, 72^\circ, 108^\circ$.

Let adjacent angles be $2x$ and $3x$.

Since adjacent angles in a parallelogram are supplementary ($180^\circ$):

$$2x + 3x = 180^\circ \implies 5x = 180^\circ \implies x = 36^\circ$$

Adjacent angles are $2(36^\circ) = 72^\circ$ and $3(36^\circ) = 108^\circ$.

Since opposite angles in a parallelogram are equal:

All four angles are $\mathbf{72^\circ, 108^\circ, 72^\circ, 108^\circ}$.

(2 Marks)
Q4. Find smallest multiplier for $252$ to make it a perfect square and find its square root.
[2 Marks]
✔ Correct Answer: Smallest multiplier = $7$, Perfect Square = $1764$, $\sqrt{1764} = 42$.

Prime factorisation of $252$:

$$252 = 2 \times 2 \times 3 \times 3 \times 7 = (2^2) \times (3^2) \times 7$$

Prime factor $7$ has no pair. Hence, $252$ must be multiplied by $\mathbf{7}$.

$$\text{New number} = 252 \times 7 = 1764$$ $$\sqrt{1764} = \sqrt{2^2 \times 3^2 \times 7^2} = 2 \times 3 \times 7 = \mathbf{42}$$
(1 Mark for multiplier + 1 Mark for square root)
Q5. Evaluate $103 \times 105$ using identity $(x + a)(x + b) = x^2 + (a + b)x + ab$.
[2 Marks]
✔ Correct Answer: $103 \times 105 = \mathbf{10815}$.

Write $103 = (100 + 3)$ and $105 = (100 + 5)$. Here $x = 100, a = 3, b = 5$.

$$(100 + 3)(100 + 5) = (100)^2 + (3 + 5)(100) + (3 \times 5)$$ $$= 10000 + 800 + 15 = \mathbf{10815}$$
(2 Marks)

Q6. Find three rational numbers between $\frac{-1}{3}$ and $\frac{1}{2}$.
[3 Marks]
✔ Correct Answer: Any three valid rational numbers e.g., $-\frac{1}{12}, 0, \frac{1}{12}, \frac{2}{12}$.

LCM of denominators $3$ and $2$ is $6$.

$$\frac{-1}{3} = \frac{-1 \times 2}{3 \times 2} = \frac{-2}{6}, \quad \frac{1}{2} = \frac{1 \times 3}{2 \times 3} = \frac{3}{6}$$

Multiply numerators and denominators by $2$ for wider range:

$$\frac{-2 \times 2}{6 \times 2} = \frac{-4}{12}, \quad \frac{3 \times 2}{6 \times 2} = \frac{6}{12}$$

Rational numbers between $\frac{-4}{12}$ and $\frac{6}{12}$ are:

$$\mathbf{-\frac{3}{12}, -\frac{2}{12}, -\frac{1}{12}, 0, \frac{1}{12}, \frac{2}{12}, \frac{3}{12}}$$

Any three numbers can be selected: e.g., $\mathbf{-\frac{1}{6}, 0, \frac{1}{6}}$.

(1 Mark LCM + 1 Mark conversion + 1 Mark final listing)
Q7. Anu and Raj present age ratio $4 : 5$. In 8 years ratio becomes $5 : 6$. Find present ages.
[3 Marks]
✔ Correct Answer: Anu's age = $32\text{ years}$, Raj's age = $40\text{ years}$.

Let present age of Anu = $4x$ years and Raj = $5x$ years.

Ages after 8 years: Anu = $(4x + 8)$, Raj = $(5x + 8)$.

$$\frac{4x + 8}{5x + 8} = \frac{5}{6}$$ $$6(4x + 8) = 5(5x + 8) \implies 24x + 48 = 25x + 40$$ $$25x - 24x = 48 - 40 \implies x = 8$$

Anu's present age = $4 \times 8 = \mathbf{32\text{ years}}$.

Raj's present age = $5 \times 8 = \mathbf{40\text{ years}}$.

(1 Mark setup + 1 Mark solving $x$ + 1 Mark final ages)
Q8. Rhombus diagonals $16\text{ cm}$ and $12\text{ cm}$. Find side length and perimeter.
[3 Marks]
✔ Correct Answer: Side = $10\text{ cm}$, Perimeter = $40\text{ cm}$.

Diagonals of a rhombus bisect each other at right angles ($90^\circ$).

Half diagonals: $OA = \frac{16}{2} = 8\text{ cm}$, $OB = \frac{12}{2} = 6\text{ cm}$.

In right $\triangle AOB$, using Pythagoras theorem:

$$\text{Side}^2 = OA^2 + OB^2 = 8^2 + 6^2 = 64 + 36 = 100$$ $$\text{Side} = \sqrt{100} = \mathbf{10\text{ cm}}$$
(2 Marks for side length)

Perimeter of rhombus = $4 \times \text{Side} = 4 \times 10 = \mathbf{40\text{ cm}}$.

(1 Mark for perimeter)
Q9. Find square root of $5625$ by long division method.
[3 Marks]
✔ Correct Answer: $\sqrt{5625} = \mathbf{75}$.

Step 1: Pair digits from right to left: $\overline{56}\;\overline{25}$.

Step 2: Largest square $\le 56$ is $7^2 = 49$. Quotient = $7$, Remainder = $56 - 49 = 7$.

Step 3: Bring down next pair $25 \implies 725$. Double quotient $7 \times 2 = 14$.

Step 4: Find digit $x$ such that $14x \times x \le 725$. $145 \times 5 = 725$.

$$\sqrt{5625} = \mathbf{75}$$
(3 Marks: 1 mark pairing + 1 mark division steps + 1 mark result)
Q10. Is $68600$ a perfect cube? Find divisor to make it perfect cube and cube root of quotient.
[3 Marks]
✔ Correct Answer: Smallest Divisor = $5$, Quotient = $13720$, wait: Prime factorisation check!

Prime factorisation of $68600$:

$$68600 = 2 \times 2 \times 2 \times 5 \times 5 \times 7 \times 7 \times 7 = (2^3) \times (5^2) \times (7^3)$$

Factors $2$ and $7$ appear in triplets, but $5$ appears only twice ($5^2 = 25$).

Therefore, $68600$ is not a perfect cube.

Smallest number to divide by = $5^2 = \mathbf{25}$.

$$\text{Quotient} = \frac{68600}{25} = 2744$$ $$\sqrt[3]{2744} = 2 \times 7 = \mathbf{14}$$
(1 Mark factorisation + 1 Mark divisor + 1 Mark cube root)

Q11. Sum of digits of a 2-digit number is 9. Interchanged number exceeds original by 27. Find original number.
[5 Marks]
✔ Correct Answer: Original Number = $\mathbf{36}$.

Let units digit = $x$. Since sum of digits = $9$, tens digit = $(9 - x)$.

Original Number = $10(9 - x) + x = 90 - 10x + x = 90 - 9x$.

When digits are interchanged, units digit becomes $(9-x)$ and tens digit becomes $x$.

New Number = $10x + (9 - x) = 9x + 9$.

(2 Marks for equation formulation)

Given: $\text{New Number} - \text{Original Number} = 27$

$$(9x + 9) - (90 - 9x) = 27$$ $$9x + 9 - 90 + 9x = 27 \implies 18x - 81 = 27$$ $$18x = 27 + 81 = 108 \implies x = \frac{108}{18} = 6$$

Tens digit = $9 - 6 = 3$, Units digit = $6$.

Original Number = $\mathbf{36}$.

(2 Marks for solving $x$ and finding number)

Verification: Interchanged number = $63$. Difference = $63 - 36 = 27$. Hence verified!

(1 Mark for verification)
Q12. (a) Quadrilateral interior angles $2x+10, 3x-20, x+30, 2x+60$. Find $x$ and angles. (b) Polygon angle sum formula & octagon sum.
[5 Marks]
✔ Correct Answer: (a) $x = 35^\circ$; Angles: $80^\circ, 85^\circ, 65^\circ, 130^\circ$ | (b) Octagon Sum = $1080^\circ$.

(a) Angle Sum Property of Quadrilateral:

$$\angle P + \angle Q + \angle R + \angle S = 360^\circ$$ $$(2x + 10) + (3x - 20) + (x + 30) + (2x + 60) = 360^\circ$$ $$8x + 80 = 360^\circ \implies 8x = 280^\circ \implies x = \mathbf{35^\circ}$$

Calculating each angle:

$$\angle P = 2(35) + 10 = \mathbf{80^\circ}$$ $$\angle Q = 3(35) - 20 = \mathbf{85^\circ}$$ $$\angle R = 35 + 30 = \mathbf{65^\circ}$$ $$\angle S = 2(35) + 60 = \mathbf{130^\circ}$$
(3 Marks)

(b) Angle sum property of an $n$-sided polygon:

$$\text{Sum of interior angles} = (n - 2) \times 180^\circ$$

For an octagon ($n = 8$):

$$\text{Sum} = (8 - 2) \times 180^\circ = 6 \times 180^\circ = \mathbf{1080^\circ}$$
(2 Marks)
Q13. (a) Simplify $(2x + 5y)^2 - (2x - 5y)^2$. (b) Factorise: (i) $a^2 + 7a + 12$, (ii) $16x^2 - 49y^2$.
[5 Marks]
✔ Correct Answer: (a) $\mathbf{40xy}$ | (b)(i) $(a + 3)(a + 4)$, (ii) $(4x - 7y)(4x + 7y)$.

(a) Using Identity $A^2 - B^2 = (A + B)(A - B)$:

Let $A = (2x + 5y)$ and $B = (2x - 5y)$.

$$(2x + 5y)^2 - (2x - 5y)^2 = [(2x + 5y) + (2x - 5y)] \times [(2x + 5y) - (2x - 5y)]$$ $$= (4x) \times (10y) = \mathbf{40xy}$$
(2.5 Marks)

(b)(i) Factorise $a^2 + 7a + 12$ by splitting middle term:

Find two numbers whose product is $12$ and sum is $7$ $\implies 3$ and $4$.

$$a^2 + 3a + 4a + 12 = a(a + 3) + 4(a + 3) = \mathbf{(a + 3)(a + 4)}$$
(1.25 Marks)

(b)(ii) Factorise $16x^2 - 49y^2$:

$$16x^2 - 49y^2 = (4x)^2 - (7y)^2 = \mathbf{(4x - 7y)(4x + 7y)}$$
(1.25 Marks)
