Q2. Find the value of the polynomial \(p(x) = 5x - 4x^2 + 3\) at \(x = -1\).
[2 Marks]
Given polynomial: \(p(x) = 5x - 4x^2 + 3\)
Substitute \(x = -1\) into the polynomial:
\(p(-1) = 5(-1) - 4(-1)^2 + 3\)
\(p(-1) = -5 - 4(1) + 3\)
\(p(-1) = -5 - 4 + 3\)
\(p(-1) = -9 + 3\)
Value of \(p(-1) = -6\)

Q4. Check whether \(x + 1\) is a factor of the polynomial \(p(x) = x^3 + x^2 + x + 1\).
[2 Marks]
By Factor Theorem, \(x + 1\) is a factor of \(p(x)\) if \(p(-1) = 0\).
Let's evaluate \(p(-1)\):
\(p(-1) = (-1)^3 + (-1)^2 + (-1) + 1\)
\(p(-1) = -1 + 1 - 1 + 1\)
\(p(-1) = 0\)
Since remainder is 0, YES, \(x + 1\) is a factor.

Q6. Plot the points \(A(1, 1)\), \(B(1, -2)\), \(C(-3, -2)\), and \(D(-3, 1)\). Identify the figure and find its area.
[3 Marks]
(Students should plot this on a graph paper. Ensure accurate placement in respective quadrants.)
Upon plotting and joining A-B-C-D-A, we observe:
  • \(AB\) is parallel to y-axis (length = \(|1 - (-2)| = 3\) units)
  • \(CD\) is parallel to y-axis (length = \(|1 - (-2)| = 3\) units)
  • \(AD\) is parallel to x-axis (length = \(|1 - (-3)| = 4\) units)
  • \(BC\) is parallel to x-axis (length = \(|1 - (-3)| = 4\) units)
Since opposite sides are equal and angles are \(90^\circ\) (due to axis parallel lines), the figure is a rectangle.
Figure formed is a Rectangle.

Area = length × breadth = \(AD \times AB\) = \(4 \times 3\)
Area = 12 square units
Q7. Factorise: \(12x^2 - 7x + 1\)
[3 Marks]
We use splitting the middle term method.
We need two numbers that multiply to \((12 \times 1) = 12\) and add to \(-7\).
The numbers are \(-4\) and \(-3\).
\(12x^2 - 4x - 3x + 1\)
Group terms: \((12x^2 - 4x) - (3x - 1)\)
Take out common factors: \(4x(3x - 1) - 1(3x - 1)\)
Factor out \((3x - 1)\):
\((3x - 1)(4x - 1)\)
Q8. Express the linear equation "The cost of a notebook is twice the cost of a pen" and find three solutions.
[3 Marks]
Let the cost of a notebook be \(Rs. x\)
Let the cost of a pen be \(Rs. y\)
According to the problem: Cost of notebook = 2 × Cost of pen
Equation: \(x = 2y\) or \(x - 2y = 0\)

Finding three solutions (assuming \(y\) values to find \(x\)):
  • If \(y = 10\) (pen costs Rs.10), then \(x = 2(10) = 20\). Solution: \((20, 10)\)
  • If \(y = 15\) (pen costs Rs.15), then \(x = 2(15) = 30\). Solution: \((30, 15)\)
  • If \(y = 20\) (pen costs Rs.20), then \(x = 2(20) = 40\). Solution: \((40, 20)\)
Three solutions: \((20, 10), (30, 15), (40, 20)\)
(Note: Any valid mathematical solution like (0,0), (2,1) is correct, but contextual values are better).
Q9. Evaluate using a suitable identity: \((104)^3\)
[3 Marks]
We can write \(104\) as \((100 + 4)\).
Using identity: \((a + b)^3 = a^3 + b^3 + 3ab(a + b)\)
Here, \(a = 100\) and \(b = 4\).
\((100 + 4)^3 = (100)^3 + (4)^3 + 3(100)(4)(100 + 4)\)
\(= 1000000 + 64 + 1200(104)\)
\(= 1000000 + 64 + 124800\)
\(= 1124864\)
Final Value = 1,124,864
Q10. Find the value of \(k\), if \(x - 1\) is a factor of \(p(x) = kx^2 - \sqrt{2}x + 1\).
[3 Marks]
If \(x - 1\) is a factor of \(p(x)\), then by Factor Theorem, \(p(1) = 0\).
Given \(p(x) = kx^2 - \sqrt{2}x + 1\)
Substitute \(x = 1\):
\(p(1) = k(1)^2 - \sqrt{2}(1) + 1 = 0\)
\(k - \sqrt{2} + 1 = 0\)
\(k = \sqrt{2} - 1\)
\(k = \sqrt{2} - 1\)

Q11. Factorise the cubic polynomial: \(p(x) = x^3 - 23x^2 + 142x - 120\)
[5 Marks]
Step 1: Find one root using trial and error (Factor Theorem).
Factors of constant term -120 are ±1, ±2, ±3, etc.
Let's try \(x = 1\):
\(p(1) = (1)^3 - 23(1)^2 + 142(1) - 120\)
\(p(1) = 1 - 23 + 142 - 120\)
\(p(1) = 143 - 143 = 0\)
Since \(p(1) = 0\), therefore \((x - 1)\) is a factor.
Step 2: Divide \(p(x)\) by \((x - 1)\) to find the quadratic quotient.
Using long division or synthetic division:
x² - 22x + 120 _________________________ x-1 | x³ - 23x² + 142x - 120 - (x³ - x²) ------------- - 22x² + 142x - (-22x² + 22x) --------------- 120x - 120 - (120x - 120) ------------ 0
Quotient is \(q(x) = x^2 - 22x + 120\)
Step 3: Factorise the quadratic quotient.
\(x^2 - 22x + 120\)
Find numbers that multiply to 120 and add to -22. They are -10 and -12.
\(= x^2 - 10x - 12x + 120\)
\(= x(x - 10) - 12(x - 10)\)
\(= (x - 10)(x - 12)\)
Step 4: Combine all factors.
\(p(x) = (x - 1)(x - 10)(x - 12)\)
(1.5 marks for finding first factor, 2 marks for division, 1.5 marks for splitting middle term)
Q12. (a) Expand: \((-2x + 5y - 3z)^2\). (b) Find value: \((-12)^3 + (7)^3 + (5)^3\) without calculating cubes.
[5 Marks]
Part (a) [2.5 Marks]
Identity used: \((a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca\)
Here \(a = -2x, b = 5y, c = -3z\)
\((-2x + 5y - 3z)^2 = (-2x)^2 + (5y)^2 + (-3z)^2 + 2(-2x)(5y) + 2(5y)(-3z) + 2(-3z)(-2x)\)
\(= 4x^2 + 25y^2 + 9z^2 - 20xy - 30yz + 12zx\)
Part (b) [2.5 Marks]
Let \(x = -12, y = 7, z = 5\)
Check their sum: \(x + y + z = -12 + 7 + 5 = -12 + 12 = 0\)
Identity: If \(x + y + z = 0\), then \(x^3 + y^3 + z^3 = 3xyz\)
\((-12)^3 + (7)^3 + (5)^3 = 3(-12)(7)(5)\)
\(= 3(-12)(35)\)
\(= -36 \times 35\)
Value = -1260
