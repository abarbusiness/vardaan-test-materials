General Instructions:
  • All questions are compulsory.
  • The paper is divided into three sections: A, B, and C.

  • Section C: 3 Questions (5 Marks each).
  • Draw neat and clean Cartesian planes wherever necessary.
SECTION A (10 Marks)(Attempt all questions - 2 Marks Each)
1.
Write the coordinates of the point which lies on both the x-axis and y-axis. What is this point called?
[2]
2.
Find the value of the polynomial \(p(x) = 5x - 4x^2 + 3\) at \(x = -1\).
[2]
3.
In which quadrant or on which axis do each of the points \((-2, 4)\) and \((0, -3)\) lie?
[2]
4.
Check whether \(x + 1\) is a factor of the polynomial \(x^3 + x^2 + x + 1\).
[2]
5.
Write the equation \(x = 3y\) in the form \(ax + by + c = 0\) and indicate the values of \(a, b,\) and \(c\).
[2]
SECTION B (15 Marks)(Short Answer Type - 3 Marks Each)
6.
Plot the points \(A(1, 1)\), \(B(1, -2)\), \(C(-3, -2)\), and \(D(-3, 1)\) on a Cartesian plane. Identify the figure formed by joining them in order and find its area.
[3]
7.
Factorise: \(12x^2 - 7x + 1\)
[3]
8.
Express the following linear equation in two variables and find three different solutions for it:
"The cost of a notebook is twice the cost of a pen."
[3]
9.
Evaluate using a suitable identity: \((104)^3\)
[3]
10.
Find the value of \(k\), if \(x - 1\) is a factor of \(p(x) = kx^2 - \sqrt{2}x + 1\).
[3]
SECTION C (15 Marks)(Long Answer Type - 5 Marks Each)
11.
Factorise the cubic polynomial:
\(x^3 - 23x^2 + 142x - 120\)
(Show all steps clearly using factor theorem and long division or synthetic division).
[5]
12.
(a)
Expand using suitable identities: \((-2x + 5y - 3z)^2\). (2.5 marks)
(b)
Without actually calculating the cubes, find the value of: \((-12)^3 + (7)^3 + (5)^3\). Mention the identity used. (2.5 marks)
[5]
13.
Draw the graph of the linear equation \(2x + y = 6\). From the graph, check whether the points \((3, 0)\) and \((1, 5)\) lie on the line. Also, find the coordinates of the points where the graph cuts the x-axis and the y-axis.
