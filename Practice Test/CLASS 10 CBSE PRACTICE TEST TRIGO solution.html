SECTION A (2 Marks Each)
Q1.
Evaluate: $\frac{2 \tan 30^\circ}{1 + \tan^2 30^\circ}$
[2 Marks]
Solution:

Substitute $\tan 30^\circ = \frac{1}{\sqrt{3}}$:

$$ = \frac{2 \left(\frac{1}{\sqrt{3}}\right)}{1 + \left(\frac{1}{\sqrt{3}}\right)^2} = \frac{\frac{2}{\sqrt{3}}}{1 + \frac{1}{3}} = \frac{\frac{2}{\sqrt{3}}}{\frac{4}{3}} = \frac{2}{\sqrt{3}} \times \frac{3}{4} = \frac{\sqrt{3}}{2} $$

Final Answer: $\frac{\sqrt{3}}{2}$

Q2.
If $\sin(A - B) = \frac{1}{2}$ and $\cos(A + B) = \frac{1}{2}$, find A and B.
[2 Marks]
Solution:

$\sin(A - B) = \frac{1}{2} \implies A - B = 30^\circ$ (1)

$\cos(A + B) = \frac{1}{2} \implies A + B = 60^\circ$ (2)

Adding (1) and (2): $2A = 90^\circ \implies A = 45^\circ$. Substituting gives $B = 15^\circ$.

Final Answer: $A = 45^\circ, B = 15^\circ$

Q3.
Prove: $(\sec A + \tan A)(1 - \sin A) = \cos A$
[2 Marks]
Solution:
$$ = \left( \frac{1 + \sin A}{\cos A} \right) (1 - \sin A) = \frac{1 - \sin^2 A}{\cos A} = \frac{\cos^2 A}{\cos A} = \cos A $$

Hence Proved.

Q4.
Find value: $9 \sec^2 A - 9 \tan^2 A$
[2 Marks]
Solution:

Expression: $9 (\sec^2 A - \tan^2 A)$. We know $1 + \tan^2 A = \sec^2 A \implies \sec^2 A - \tan^2 A = 1$.

$= 9(1) = 9$.

Final Answer: 9

Q5.
Tower shadow is $\sqrt{3}$ times height. Find sun's elevation.
[2 Marks]
Solution:

Let height = $h$, Shadow = $h\sqrt{3}$. $\tan \theta = \frac{h}{h\sqrt{3}} = \frac{1}{\sqrt{3}}$. Thus, $\theta = 30^\circ$.

Final Answer: $30^\circ$

Q6.
If $\tan A = \frac{4}{3}$, find $\sin A + \cos A$.
[2 Marks]
Solution:

Perp = 4, Base = 3. Hyp $= \sqrt{16+9} = 5$.

$\sin A + \cos A = \frac{4}{5} + \frac{3}{5} = \frac{7}{5}$.

Final Answer: $7/5$

Q7.
Evaluate: $\frac{\sin^2 63^\circ + \sin^2 27^\circ}{\cos^2 17^\circ + \cos^2 73^\circ}$
[2 Marks]
Solution:

Using $\sin(90^\circ - \theta) = \cos \theta$: $\frac{\sin^2 63^\circ + \cos^2 63^\circ}{\cos^2 17^\circ + \sin^2 17^\circ} = \frac{1}{1} = 1$.

Final Answer: 1

Q8.
A ladder 15m long makes an angle of $60^\circ$ with the wall. Find height of wall.
[2 Marks]
Solution:

Angle is with the wall. $\cos 60^\circ = \frac{\text{Wall Height}}{\text{Ladder}} \implies \frac{1}{2} = \frac{\text{Height}}{15} \implies \text{Height} = 7.5$ m.

Final Answer: 7.5 m

Q9.
Prove: $(\sin \theta + \cos \theta)^2 = 1 + 2 \sin \theta \cos \theta$
[2 Marks]
Solution:

L.H.S $= \sin^2 \theta + \cos^2 \theta + 2\sin \theta \cos \theta = 1 + 2\sin \theta \cos \theta = \text{R.H.S.}$

Hence Proved.

Q10.
Find the value of $(\sec^2 \theta - 1)(1 - \text{cosec}^2 \theta)$.
[2 Marks]
Solution:

$(\tan^2 \theta) \times (-\cot^2 \theta) = -\tan^2 \theta \times \frac{1}{\tan^2 \theta} = -1$.

Final Answer: -1

Q11.
If $\sin \theta = \cos \theta$, find the value of $2 \tan^2 \theta + \sin^2 \theta - 1$.
[2 Marks]
Solution:

$\sin \theta = \cos \theta \implies \theta = 45^\circ$. Sub: $2(1)^2 + (\frac{1}{\sqrt{2}})^2 - 1 = 2 + 0.5 - 1 = 1.5$.

Final Answer: 1.5 (or $3/2$)

Q12.
In right $\Delta PQR$, $PR + QR = 25$ and $PQ = 5$. Find $\sin P$.
[2 Marks]
Solution:

By Pythagoras: $PR^2 - QR^2 = 5^2 = 25 \implies (PR-QR)(25) = 25 \implies PR - QR = 1$.

Solving: $PR=13, QR=12$. $\sin P = \frac{QR}{PR} = \frac{12}{13}$.

Final Answer: $12/13$

Q13.
If $\sin(A+2B) = \frac{\sqrt{3}}{2}$ and $\cos(A+4B) = 0$, find A and B.
[2 Marks]
Solution:

$A+2B = 60^\circ$ and $A+4B = 90^\circ$.

Subtracting: $2B = 30^\circ \implies B = 15^\circ$. Substituting $B$, we get $A = 30^\circ$.

Final Answer: $A=30^\circ, B=15^\circ$

Q14.
Prove $\frac{\sin^3 \theta + \cos^3 \theta}{\sin \theta + \cos \theta} + \sin \theta \cos \theta = 1$.
[2 Marks]
Solution:

Expand numerator: $\frac{(\sin \theta + \cos \theta)(\sin^2 \theta + \cos^2 \theta - \sin \theta \cos \theta)}{\sin \theta + \cos \theta} + \sin \theta \cos \theta$

$= (1 - \sin \theta \cos \theta) + \sin \theta \cos \theta = 1 = \text{R.H.S.}$

Hence Proved.

Q15.
Pole shadow is $2\sqrt{3}$ m, sun elevation $60^\circ$. Find pole height.
[2 Marks]
Solution:

$\tan 60^\circ = \frac{h}{2\sqrt{3}} \implies \sqrt{3} = \frac{h}{2\sqrt{3}} \implies h = \sqrt{3} \times 2\sqrt{3} = 6$ m.

Final Answer: 6 m

SECTION B (3 Marks Each)
Q16.
If $3 \cot A = 4$, check whether $\frac{1 - \tan^2 A}{1 + \tan^2 A} = \cos^2 A - \sin^2 A$.
[3 Marks]
Solution:

$\tan A = \frac{3}{4}$, $\sin A = \frac{3}{5}$, $\cos A = \frac{4}{5}$.

L.H.S: $\frac{1 - 9/16}{1 + 9/16} = \frac{7/16}{25/16} = \frac{7}{25}$

R.H.S: $(4/5)^2 - (3/5)^2 = \frac{16}{25} - \frac{9}{25} = \frac{7}{25}$

Final Answer: TRUE.

Q17.
Prove: $\frac{\cos A}{1 + \sin A} + \frac{1 + \sin A}{\cos A} = 2 \sec A$
[3 Marks]
Solution:
$$ = \frac{\cos^2 A + 1 + 2\sin A + \sin^2 A}{(1 + \sin A)\cos A} = \frac{2 + 2\sin A}{(1 + \sin A)\cos A} = \frac{2}{\cos A} = 2 \sec A $$

Hence Proved.

Q18.
Prove: $\sqrt{\frac{1 + \sin A}{1 - \sin A}} = \sec A + \tan A$
[3 Marks]
Solution:
$$ = \sqrt{\frac{(1 + \sin A)^2}{1 - \sin^2 A}} = \frac{1 + \sin A}{\cos A} = \frac{1}{\cos A} + \frac{\sin A}{\cos A} = \sec A + \tan A $$

Hence Proved.

Q19.
Kite height 60m. String elevation $60^\circ$. Find string length.
[3 Marks]
Solution:

$\sin 60^\circ = \frac{60}{L} \implies \frac{\sqrt{3}}{2} = \frac{60}{L} \implies L = 40\sqrt{3}$ m.

Final Answer: $40\sqrt{3}$ m.

Q20.
Prove: $(\sin A + \text{cosec} A)^2 + (\cos A + \sec A)^2 = 7 + \tan^2 A + \cot^2 A$
[3 Marks]
Solution:
$$ = \sin^2 A + \text{cosec}^2 A + 2 + \cos^2 A + \sec^2 A + 2 = 5 + (1 + \cot^2 A) + (1 + \tan^2 A) $$ $$ = 7 + \tan^2 A + \cot^2 A $$

Hence Proved.

Q21.
If $\sec \theta = x + \frac{1}{4x}$, prove $\sec \theta + \tan \theta = 2x$ or $\frac{1}{2x}$.
[3 Marks]
Solution:
$$ \tan^2 \theta = \left(x + \frac{1}{4x}\right)^2 - 1 = \left(x - \frac{1}{4x}\right)^2 \implies \tan \theta = \pm \left(x - \frac{1}{4x}\right) $$

Case +: $\left(x + \frac{1}{4x}\right) + \left(x - \frac{1}{4x}\right) = 2x$. Case -: equals $\frac{1}{2x}$. Hence Proved.

Q22.
Prove $\frac{\sin \theta - \cos \theta + 1}{\sin \theta + \cos \theta - 1} = \frac{1}{\sec \theta - \tan \theta}$
[3 Marks]
Solution:

Divide by $\cos \theta$: $\frac{(\tan \theta + \sec \theta) - (\sec^2 \theta - \tan^2 \theta)}{\tan \theta - \sec \theta + 1} = \sec \theta + \tan \theta = \frac{1}{\sec \theta - \tan \theta}$.

Hence Proved.

Q23.
Building elevation $30^\circ$, tower $60^\circ$. Tower is 50m. Find building height.
[3 Marks]
Solution:

Tower base distance $x = \frac{50}{\sqrt{3}}$. Building height $h = x \tan 30^\circ = \frac{50}{\sqrt{3}} \times \frac{1}{\sqrt{3}} = 16.67$ m.

Final Answer: $16.67$ m.

Q24.
If $\frac{\cos \alpha}{\cos \beta} = m$ and $\frac{\cos \alpha}{\sin \beta} = n$, show $(m^2 + n^2) \cos^2 \beta = n^2$.
[3 Marks]
Solution:
$$ \left( \frac{\cos^2 \alpha}{\cos^2 \beta} + \frac{\cos^2 \alpha}{\sin^2 \beta} \right) \cos^2 \beta = \cos^2 \alpha \left( \frac{1}{\cos^2 \beta \sin^2 \beta} \right) \cos^2 \beta = \frac{\cos^2 \alpha}{\sin^2 \beta} = n^2 $$

Hence Proved.

Q25.
Observer $1.5$m tall, $28.5$m from chimney. Elevation $45^\circ$. Find chimney height.
[3 Marks]
Solution:

Height above eyes $= 28.5 \times 1 = 28.5$ m. Total $= 28.5 + 1.5 = 30$ m.

Final Answer: 30 m.

Q26.
If $x \sin^3 \theta + y \cos^3 \theta = \sin \theta \cos \theta$ and $x \sin \theta = y \cos \theta$, prove $x^2 + y^2 = 1$.
[3 Marks]
Solution:

Substitute $x \sin \theta = y \cos \theta$: $(y \cos \theta)\sin^2 \theta + y \cos^3 \theta = y \cos \theta(\sin^2 \theta + \cos^2 \theta) = y \cos \theta$.

Thus $y \cos \theta = \sin \theta \cos \theta \implies y = \sin \theta$. Then $x = \cos \theta$.

$x^2 + y^2 = \cos^2 \theta + \sin^2 \theta = 1$. Hence Proved.

Q27.
Prove: $(1 + \cot A - \text{cosec} A)(1 + \tan A + \sec A) = 2$.
[3 Marks]
Solution:
$$ = \left( \frac{\sin A + \cos A - 1}{\sin A} \right) \left( \frac{\cos A + \sin A + 1}{\cos A} \right) = \frac{(\sin A + \cos A)^2 - 1}{\sin A \cos A} $$ $$ = \frac{1 + 2\sin A \cos A - 1}{\sin A \cos A} = 2 $$

Hence Proved.

Q28.
Building 7m. Tower elev $60^\circ$, dep $45^\circ$. Find tower height.
[3 Marks]
Solution:

Dist $x = 7/\tan 45^\circ = 7$ m. Tower height above building $= 7 \tan 60^\circ = 7\sqrt{3}$.

Total $= 7 + 7\sqrt{3} = 7(\sqrt{3}+1)$ m.

Final Answer: $7(\sqrt{3}+1)$ m.

Q29.
If $\cos \theta + \sin \theta = \sqrt{2} \cos \theta$, show $\cos \theta - \sin \theta = \sqrt{2} \sin \theta$.
[3 Marks]
Solution:

$\sin \theta = (\sqrt{2}-1)\cos \theta$. Multiply by $(\sqrt{2}+1)$:

$(\sqrt{2}+1)\sin \theta = (2-1)\cos \theta \implies \sqrt{2}\sin \theta + \sin \theta = \cos \theta \implies \cos \theta - \sin \theta = \sqrt{2}\sin \theta$.

Hence Proved.

Q30.
Tower elevation $60^\circ$. From 10m vertically above, elev $45^\circ$. Find tower height.
[3 Marks]
Solution:

Let height $H$, dist $x$. $H = x\sqrt{3}$ and $H-10 = x \tan 45^\circ = x$.

Sub $x = H-10$: $H = (H-10)\sqrt{3} \implies H(\sqrt{3}-1) = 10\sqrt{3} \implies H = \frac{10\sqrt{3}(\sqrt{3}+1)}{2} = 5(3+\sqrt{3})$ m.

Final Answer: $5(3+\sqrt{3})$ m.

SECTION C (4 Marks Each)
Q31.
Two equal poles on 80m road. Elevations $60^\circ, 30^\circ$. Find heights and distances.
[4 Marks]
Solution:

$h = x\sqrt{3}$ and $h = \frac{80-x}{\sqrt{3}} \implies 3x = 80-x \implies x=20$.

Final Answer: Heights = $20\sqrt{3}$ m. Distances = 20m, 60m.

Q32.
TV tower on canal. Elevation $60^\circ$. From 20m further, $30^\circ$. Find height & width.
[4 Marks]
Solution:

$h = x\sqrt{3}$ and $h = \frac{x+20}{\sqrt{3}} \implies 3x = x+20 \implies x=10$.

Final Answer: Height = $10\sqrt{3}$ m, Width = 10m.

Q33.
Prove $\frac{\tan^3 \theta}{1 + \tan^2 \theta} + \frac{\cot^3 \theta}{1 + \cot^2 \theta} = \sec \theta \text{cosec} \theta - 2 \sin \theta \cos \theta$
[4 Marks]
Solution:
$$ = \frac{\sin^3 \theta}{\cos \theta} + \frac{\cos^3 \theta}{\sin \theta} = \frac{\sin^4 \theta + \cos^4 \theta}{\sin \theta \cos \theta} = \frac{1 - 2\sin^2 \theta \cos^2 \theta}{\sin \theta \cos \theta} $$ $$ = \sec \theta \text{cosec} \theta - 2\sin \theta \cos \theta $$

Hence Proved.

Q34.
If $m = \cos A - \sin A, n = \cos A + \sin A$, show $\frac{m^2 + n^2}{m^2 - n^2} = -\frac{1}{2} \sec A \text{cosec} A$
[4 Marks]
Solution:

$m^2+n^2 = 2$ and $m^2-n^2 = -4\sin A\cos A$.

Ratio $= \frac{2}{-4\sin A\cos A} = -\frac{1}{2}\sec A\text{cosec} A$. Hence Proved.

Q35.
Highway car. Tower dep $30^\circ \to 60^\circ$ in 6s. Find time to foot.
[4 Marks]
Solution:

$h = d\sqrt{3}$ and $h = (d+6v)/\sqrt{3} \implies 3d = d+6v \implies 2d = 6v \implies d = 3v$.

Time $= d/v = 3v/v = 3$ seconds.

Final Answer: 3 Seconds.

SECTION D (5 Marks Each)
Q36.
Prove $\frac{\tan \theta}{1 - \cot \theta} + \frac{\cot \theta}{1 - \tan \theta} = 1 + \sec \theta \text{cosec} \theta$
[5 Marks]
Solution:
$$ = \frac{\sin^3 \theta - \cos^3 \theta}{\sin \theta \cos \theta (\sin \theta - \cos \theta)} = \frac{1 + \sin \theta \cos \theta}{\sin \theta \cos \theta} = \sec \theta \text{cosec} \theta + 1 $$

Hence Proved.

Q37.
If $\sin \theta + \cos \theta = \sqrt{3}$, prove that $\tan \theta + \cot \theta = 1$.
[5 Marks]
Solution:

Squaring: $1 + 2\sin \theta \cos \theta = 3 \implies \sin \theta \cos \theta = 1$.

$\tan \theta + \cot \theta = \frac{1}{\sin \theta \cos \theta} = 1$. Hence Proved.

Q38.
Girl spots balloon. Height 88.2m. Elevation $60^\circ \to 30^\circ$. Find distance.
[5 Marks]
Solution:

Height above eyes $= 87$ m. $x = 87/\sqrt{3} = 29\sqrt{3}$ m. $x+y = 87\sqrt{3}$ m.

Distance $y = 87\sqrt{3} - 29\sqrt{3} = 58\sqrt{3}$ m.

Final Answer: $58\sqrt{3}$ m.

Q39.
Plane elevation $60^\circ \to 30^\circ$. Height $1500\sqrt{3}$m. 15s. Find speed in km/hr.
[5 Marks]
Solution:

$x = 1500$ m, $x+y = 4500$ m. Dist $y = 3000$ m.

Speed $= 3000/15 = 200$ m/s $= 720$ km/hr.

Final Answer: 720 km/hr.

Q40.
Cloud elevation $30^\circ$, reflection depression $60^\circ$ from 60m above lake. Find cloud height.
[5 Marks]
Solution:

$x = \sqrt{3}(H-60)$ and $x = (H+60)/\sqrt{3}$.

$3(H-60) = H+60 \implies 2H = 240 \implies H = 120$ m.

Final Answer: 120 m.

Q41.
If $\sec \theta + \tan \theta = p$, prove $\sin \theta = \frac{p^2 - 1}{p^2 + 1}$.
[5 Marks]
Solution:

$\sec \theta - \tan \theta = 1/p$. $2\tan \theta = p - 1/p = \frac{p^2-1}{p}$ and $2\sec \theta = \frac{p^2+1}{p}$.

$\sin \theta = \frac{\tan \theta}{\sec \theta} = \frac{p^2-1}{p^2+1}$. Hence Proved.

Q42.
Prove $\frac{\cos A - \sin A + 1}{\cos A + \sin A - 1} = \text{cosec} A + \cot A$.
[5 Marks]
Solution:

Divide by $\sin A$: $\frac{\cot A - 1 + \text{cosec} A}{\cot A + 1 - \text{cosec} A}$.

$$ = \frac{(\cot A + \text{cosec} A) - (\text{cosec}^2 A - \cot^2 A)}{\cot A - \text{cosec} A + 1} = \text{cosec} A + \cot A $$

Hence Proved.

Q43.
Aeroplane at 300m. Depression to banks $45^\circ$ and $60^\circ$. Find river width.
[5 Marks]
Solution:

Distances $x$ and $y$. $\tan 45^\circ = 300/x \implies x=300$. $\tan 60^\circ = 300/y \implies y = 100\sqrt{3}$.

Width $= 300 + 173.2 = 473.2$ m.

Final Answer: 473.2 m.

Q44.
Prove $\frac{\tan \theta + \sec \theta - 1}{\tan \theta - \sec \theta + 1} = \frac{1 + \sin \theta}{\cos \theta}$.
[5 Marks]
Solution:

Substitute $1 = \sec^2 \theta - \tan^2 \theta$ in numerator.

Factor out $(\sec \theta + \tan \theta)$, denominator cancels out.

Result $= \sec \theta + \tan \theta = \frac{1}{\cos \theta} + \frac{\sin \theta}{\cos \theta}$. Hence Proved.

Q45.
Boy bird dist 100m, elev $30^\circ$. Girl on 20m building, elev $45^\circ$. Find girl to bird dist.
[5 Marks]
Solution:

Bird height $= 100 \sin 30^\circ = 50$ m. Height above girl $= 50 - 20 = 30$ m.

Dist $d = 30 / \sin 45^\circ = 30\sqrt{2}$ m.

Final Answer: $30\sqrt{2}$ m.

Q46.
If $\tan \theta = \frac{1}{\sqrt{7}}$, evaluate $\frac{\text{cosec}^2 \theta - \sec^2 \theta}{\text{cosec}^2 \theta + \sec^2 \theta}$.
[5 Marks]
Solution:

$\cot \theta = \sqrt{7}$. $\text{cosec}^2 \theta = 1+7=8$. $\sec^2 \theta = 1+1/7 = 8/7$.

Expr $= \frac{8 - 8/7}{8 + 8/7} = \frac{56-8}{56+8} = \frac{48}{64} = \frac{3}{4}$.

Final Answer: $3/4$
