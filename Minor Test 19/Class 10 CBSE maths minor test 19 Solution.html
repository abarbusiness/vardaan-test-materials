Q1. If $a = x^3 y^2$ and $b = x y^3$, where $x, y$ are primes, find $\text{HCF}(a, b)$.
[1 Mark]
Correct Option: (b) $x y^2$
HCF is the product of the smallest power of each common prime factor involved in the numbers.
$$\text{HCF}(a, b) = x^{\min(3, 1)} \cdot y^{\min(2, 3)} = x^1 \cdot y^2 = x y^2$$
Q2. If one zero of $x^2 + 3x + k$ is $2$, find $k$.
[1 Mark]
Correct Option: (b) $-10$
Since $x = 2$ is a zero of $p(x) = x^2 + 3x + k$, we have $p(2) = 0$:
$$(2)^2 + 3(2) + k = 0 \implies 4 + 6 + k = 0 \implies k = -10$$
Q3. Find $k$ for infinitely many solutions of $kx + 3y = -(k-3)$ and $12x + ky = -k$.
[1 Mark]
Correct Option: (a) $k = 6$
Condition for infinitely many solutions: $\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$
$$\frac{k}{12} = \frac{3}{k} = \frac{k-3}{k}$$
From $\frac{k}{12} = \frac{3}{k} \implies k^2 = 36 \implies k = \pm 6$.
For $k = 6$: $\frac{6}{12} = \frac{3}{6} = \frac{6-3}{6} = \frac{1}{2}$ (Satisfies all ratios).
Q4. Value of $k$ for equal roots in $2x^2 - kx + 8 = 0$.
[1 Mark]
Correct Option: (c) $\pm 8$
For equal roots, Discriminant $D = b^2 - 4ac = 0$.
$$(-k)^2 - 4(2)(8) = 0 \implies k^2 - 64 = 0 \implies k = \pm 8$$

Q6. In $\Delta ABC, DE \parallel BC$, $AD = 3, DB = 5, AC = 5.6$. Find $AE$.
[1 Mark]
Correct Option: (a) $2.1\text{ cm}$
Geometric Representation for Q6 ($\Delta ABC$ with $DE \parallel BC$)
By Thales Theorem (Basic Proportionality Theorem): $\frac{AE}{AC} = \frac{AD}{AB} = \frac{AD}{AD + DB} = \frac{3}{3+5} = \frac{3}{8}$.
$$AE = \frac{3}{8} \times 5.6 = 3 \times 0.7 = 2.1\text{ cm}$$

SECTION B (10 Marks) — Very Short Answer Solutions
Q21. Prove that $5 - \sqrt{3}$ is irrational.
[2 Marks]
Proof Complete
Let us assume to the contrary that $5 - \sqrt{3}$ is rational.
Then there exist co-prime integers $a$ and $b$ ($b \neq 0$) such that:
$$5 - \sqrt{3} = \frac{a}{b} \implies \sqrt{3} = 5 - \frac{a}{b} = \frac{5b - a}{b}$$
Since $a$ and $b$ are integers, $\frac{5b - a}{b}$ is rational. Consequently, $\sqrt{3}$ must be rational.
But this contradicts the given fact that $\sqrt{3}$ is irrational.
Hence, our assumption was incorrect, and $5 - \sqrt{3}$ is irrational.
Q22. Zeroes of $4s^2 - 4s + 1$ and verification of coefficients.
[2 Marks]
Zeroes: $s = \frac{1}{2}, \frac{1}{2}$
$$4s^2 - 4s + 1 = 0 \implies (2s - 1)^2 = 0 \implies s = \frac{1}{2}, \frac{1}{2}$$
Verification:
$$\text{Sum of zeroes } \alpha + \beta = \frac{1}{2} + \frac{1}{2} = 1 = -\frac{-4}{4} = -\frac{b}{a}$$
$$\text{Product of zeroes } \alpha \beta = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4} = \frac{c}{a}$$
Q23. Solve $2x + 3y = 11$ and $2x - 4y = -24$. Find $m$ in $y = mx + 3$.
[2 Marks]
Final Answer: $x = -2, y = 5, m = -1$
Subtracting equation (2) from (1):
$$(2x + 3y) - (2x - 4y) = 11 - (-24) \implies 7y = 35 \implies y = 5$$
Substitute $y = 5$ in $2x + 3(5) = 11 \implies 2x = 11 - 15 = -4 \implies x = -2$.
Now substitute $x = -2, y = 5$ in $y = mx + 3$:
$$5 = m(-2) + 3 \implies 2 = -2m \implies m = -1$$
Q24. In isosceles $\Delta ABC$ ($AB = AC$), $AD \perp BC, EF \perp AC$. Prove $\Delta ABD \sim \Delta ECF$.

Geometric Diagram for Q24 (Isosceles $\Delta ABC$ with Perpendiculars)

In $\Delta ABD$ and $\Delta ECF$:
• $\angle ADB = \angle EFC = 90^\circ$ (Given perpendiculars)

Q25. Evaluate $\frac{5\cos^2 60^\circ + 4\sec^2 30^\circ - \tan^2 45^\circ}{\sin^2 30^\circ + \cos^2 30^\circ}$.
[2 Marks]
Final Answer: $\frac{67}{12}$

Hence, expression value $= \frac{67}{12}$.

Q26. Sum of all 3-digit natural numbers divisible by $7$.
[3 Marks]
Final Answer: $S_n = 70,336$
First 3-digit number divisible by 7 is $105$, and the last is $994$.
The AP is $105, 112, 119, \dots, 994$ with $a = 105, d = 7, a_n = 994$.
$$a_n = a + (n - 1)d \implies 994 = 105 + (n - 1)7 \implies (n - 1)7 = 889 \implies n - 1 = 127 \implies n = 128$$
$$S_{128} = \frac{n}{2}(a + l) = \frac{128}{2}(105 + 994) = 64 \times 1099 = 70336$$
Q27. Solve $\frac{1}{x+4} - \frac{1}{x-7} = \frac{11}{30}$.
[3 Marks]
Final Answer: $x = 1$ or $x = 2$
$$\frac{(x - 7) - (x + 4)}{(x + 4)(x - 7)} = \frac{11}{30} \implies \frac{-11}{x^2 - 3x - 28} = \frac{11}{30}$$
$$-1(30) = 1(x^2 - 3x - 28) \implies x^2 - 3x - 28 + 30 = 0 \implies x^2 - 3x + 2 = 0$$
$$(x - 1)(x - 2) = 0 \implies x = 1 \quad \text{or} \quad x = 2$$
Q28. Ratio in which $2x + y - 4 = 0$ divides $A(2,-2)$ and $B(3,7)$.
[3 Marks]
Final Answer: Ratio $2 : 9$, Point $\left(\frac{24}{11}, \frac{-4}{11}\right)$
Let ratio be $k : 1$. Coordinates of dividing point $P$:
$$P = \left(\frac{3k + 2}{k + 1}, \frac{7k - 2}{k + 1}\right)$$
Since $P$ lies on $2x + y - 4 = 0$:
$$2\left(\frac{3k + 2}{k + 1}\right) + \frac{7k - 2}{k + 1} - 4 = 0 \implies \frac{6k + 4 + 7k - 2 - 4k - 4}{k + 1} = 0 \implies 9k - 2 = 0 \implies k = \frac{2}{9}$$
Hence, ratio is $2 : 9$. Substituting $k = \frac{2}{9}$ into $P$ gives $\left(\frac{24}{11}, \frac{-4}{11}\right)$.
Q29. Prove $\frac{\sin \theta - 2\sin^3 \theta}{2\cos^3 \theta - \cos \theta} = \tan \theta$.
[3 Marks]
Proof Complete
$$\text{L.H.S.} = \frac{\sin \theta (1 - 2\sin^2 \theta)}{\cos \theta (2\cos^2 \theta - 1)}$$
Using identity $1 = \sin^2 \theta + \cos^2 \theta$:
$$1 - 2\sin^2 \theta = \sin^2 \theta + \cos^2 \theta - 2\sin^2 \theta = \cos^2 \theta - \sin^2 \theta$$
$$2\cos^2 \theta - 1 = 2\cos^2 \theta - (\sin^2 \theta + \cos^2 \theta) = \cos^2 \theta - \sin^2 \theta$$
$$\text{L.H.S.} = \frac{\sin \theta (\cos^2 \theta - \sin^2 \theta)}{\cos \theta (\cos^2 \theta - \sin^2 \theta)} = \frac{\sin \theta}{\cos \theta} = \tan \theta = \text{R.H.S.}$$
Q30. State and Prove Basic Proportionality Theorem.
[3 Marks]
Proof Complete
Statement: If a line is drawn parallel to one side of a triangle to intersect the other two sides in distinct points, the other two sides are divided in the same ratio.
Proof Construction Diagram for Thales Theorem (BPT)
Given: In $\Delta ABC$, $DE \parallel BC$.
To Prove: $\frac{AD}{DB} = \frac{AE}{EC}$.
Construction: Join $BE$ and $CD$. Draw $DM \perp AC$ and $EN \perp AB$.
$$\text{Area}(\Delta ADE) = \frac{1}{2} \times AD \times EN, \quad \text{Area}(\Delta BDE) = \frac{1}{2} \times DB \times EN \implies \frac{\text{Area}(\Delta ADE)}{\text{Area}(\Delta BDE)} = \frac{AD}{DB} \quad \text{--- (1)}$$
$$\text{Area}(\Delta ADE) = \frac{1}{2} \times AE \times DM, \quad \text{Area}(\Delta DEC) = \frac{1}{2} \times EC \times DM \implies \frac{\text{Area}(\Delta ADE)}{\text{Area}(\Delta DEC)} = \frac{AE}{EC} \quad \text{--- (2)}$$
Since $\Delta BDE$ and $\Delta DEC$ lie on same base $DE$ and between same parallels $DE \parallel BC$, $\text{Area}(\Delta BDE) = \text{Area}(\Delta DEC)$.
From (1) and (2), $\frac{AD}{DB} = \frac{AE}{EC}$. (Proved)
Q31. Car approaching tower: angle changes from $30^\circ$ to $60^\circ$ in 6 seconds. Find remaining time.
[3 Marks]
Final Answer: $3\text{ seconds}$
Trigonometric Diagram for Q31 (Car Approaching Tower)
Let height of tower be $h$. Let initial position be $A$, 6s position be $B$, and foot of tower be $C$.
In right triangle with angle $30^\circ$: $\tan 30^\circ = \frac{h}{AC} \implies AC = h\sqrt{3}$.
In right triangle with angle $60^\circ$: $\tan 60^\circ = \frac{h}{BC} \implies BC = \frac{h}{\sqrt{3}}$.
$$\text{Distance } AB = AC - BC = h\sqrt{3} - \frac{h}{\sqrt{3}} = \frac{2h}{\sqrt{3}}$$
Speed $= \frac{\text{Distance}}{\text{Time}} = \frac{2h/\sqrt{3}}{6} = \frac{h}{3\sqrt{3}}\text{ m/s}$.
$$\text{Time to cover } BC = \frac{\text{Distance } BC}{\text{Speed}} = \frac{h/\sqrt{3}}{h/(3\sqrt{3})} = 3\text{ seconds}$$

Q32. Solve graphically: $2x + 3y = 12$ and $x - y = 1$. Find vertices with y-axis & area.

Solution: $(3, 2)$, Vertices: $(3,2), (0,4), (0,-1)$, Area $= 7.5\text{ sq. units}$
Complete Cartesian Graph for Q32 Solution

Line 2: $x - y = 1 \implies$ Points: $(0, -1), (1, 0), (3, 2)$.

Base along y-axis $= 4 - (-1) = 5\text{ units}$, Height $= \text{x-coordinate of } A = 3\text{ units}$.
$$\text{Area} = \frac{1}{2} \times \text{Base} \times \text{Height} = \frac{1}{2} \times 5 \times 3 = 7.5\text{ sq. units}$$
Q33. Speed of motorboat $18\text{ km/h}$. Distance $24\text{ km}$. Upstream time is 1 hour more. Find stream speed.
[5 Marks]
Final Answer: $6\text{ km/h}$
Let speed of stream be $x\text{ km/h}$.
Speed upstream $= (18 - x)\text{ km/h}$, Speed downstream $= (18 + x)\text{ km/h}$.
$$\frac{24}{18 - x} - \frac{24}{18 + x} = 1 \implies 24\left(\frac{18 + x - 18 + x}{(18 - x)(18 + x)}\right) = 1$$
$$24(2x) = 324 - x^2 \implies x^2 + 48x - 324 = 0$$
$$(x + 54)(x - 6) = 0 \implies x = 6 \quad (\text{Rejecting } x = -54 \text{ as speed cannot be negative})$$
Q34. Prize fund ₹$2800$ for 4 prizes, each ₹$200$ less than previous.
[5 Marks]
Final Answers: (a) ₹1000, ₹800, ₹600, ₹400 | (b) $S_n = 100n(11 - n)$
Part (a) [3 Marks]:
Let first prize be $a$. Since each prize is ₹200 less, $d = -200$. Here $n = 4, S_4 = 2800$.
$$S_4 = \frac{4}{2}[2a + (4-1)(-200)] = 2800 \implies 2[2a - 600] = 2800 \implies 2a - 600 = 1400 \implies a = 1000$$
Prizes are ₹$1000$, ₹$800$, ₹$600$, and ₹$400$.
Part (b) [2 Marks]:
$$S_n = \frac{n}{2}[2(1000) + (n - 1)(-200)] = \frac{n}{2}[2000 - 200n + 200] = \frac{n}{2}[2200 - 200n] = 100n(11 - n)$$
Q35. Height of building $7\text{ m}$. Angle of elevation top tower $60^\circ$, depression foot $45^\circ$. Find height.
[5 Marks]
Final Answer: $7(\sqrt{3} + 1)\text{ m} \approx 19.12\text{ m}$
Trigonometric Diagram for Q35 (Building & Cable Tower)
Let distance between building and tower be $d$. Let height of tower above building top be $h$.
From depression angle to foot: $\tan 45^\circ = \frac{7}{d} = 1 \implies d = 7\text{ m}$.
From elevation angle to top: $\tan 60^\circ = \frac{h}{d} \implies \sqrt{3} = \frac{h}{7} \implies h = 7\sqrt{3}\text{ m}$.
$$\text{Total height of tower} = 7 + 7\sqrt{3} = 7(\sqrt{3} + 1) = 7(1.732 + 1) = 7 \times 2.732 = 19.124\text{ m}$$

Q38. Case Study 3: Drone height $100\text{ m}$, angles $30^\circ$ and $45^\circ$.
