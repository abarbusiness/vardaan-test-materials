Minor Test 15
Class: 6 ICSE Subject: Mathematics Time: 1 Hour Max. Marks: 40
General Instructions:
  • All questions are compulsory.
  • The paper is divided into three sections: A, B, and C.
  • Write your answers neatly and legibly. Show all necessary workings.
  • Syllabus: Ratio and Proportion, Introduction to Sets.
SECTION A (10 Marks)(Attempt all questions - 2 Marks Each)
1.
Write the following set in Roster form:
$A = \{x \mid x \text{ is a vowel in the word "EQUATION"}\}$
2.
Express the ratio $45\text{ cm}$ to $3\text{ meters}$ in its simplest form.
3.
State whether the following sets are finite or infinite:
(i) Set of all stars in the universe.
(ii) Set of multiples of $5$ which are less than $100$.
4.
Find the value of $x$ if the numbers $3, 12, 15,$ and $x$ are in proportion.
5.
Find the cardinal number of the set $B = \{x \mid x \text{ is a prime number between } 10 \text{ and } 20\}$.
SECTION B (15 Marks)(Short Answer Type - 3 Marks Each)
6.
Divide ₹$1500$ between A and B in the ratio $2:3$.
7.
Let $P = \{1, 2, 3, 4, 5\}$ and $Q = \{2, 4, 6, 8\}$. Answer the following:
(i) Write down the set of elements present in P but not in Q.
(ii) Are P and Q equivalent sets? Give a logical reason for your answer.
8.
The ratio of the length to the width of a rectangular playground is $5:3$. If the length of the playground is $80\text{ m}$, calculate its width.
9.
Rewrite the following set in Set-builder form:
$C = \{5, 10, 15, 20, 25, \dots\}$
10.
The ratio of the number of boys to girls in a school is $5:4$. If there are $800$ boys in the school, find the total number of students.
SECTION C (15 Marks)(Long Answer Type - 5 Marks Each)
11.
The cost of $12$ identical pens is ₹$180$. Calculate using the unitary method:
(a) The cost of $25$ such pens.
(b) The number of pens that can be bought for ₹$300$.
12.
Consider the set $S = \{a, b, c\}$.
(a) Write down all the possible subsets of the set $S$.
(b) Verify the mathematical property that the number of subsets is $2^n$, where $n$ represents the cardinal number of the set.
13.
Three partners Rohan, Rahul, and Raj invest ₹$30,000$, ₹$40,000$, and ₹$50,000$ respectively to start a small business. At the end of the year, they make a total profit of ₹$24,000$. Calculate the share of profit for each partner, assuming the profit is shared in the ratio of their original investments.
