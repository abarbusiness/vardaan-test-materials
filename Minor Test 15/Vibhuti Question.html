MIT 15
Class: 8 CBSE Subject: Mathematics Time: 1 Hour Max. Marks: 40
General Instructions:
  • All questions are compulsory.
  • The paper is divided into three sections: A, B, and C.
  • Write your answers neatly and legibly. Show steps clearly where required.
  • Use of calculators is not permitted.
SECTION A (10 Marks)(Attempt all questions - 2 Marks Each)
1.
Identify the terms and their respective coefficients for the expression: $5xyz^2 - 3zy$.
2.
Classify the following polynomials as monomials, binomials, or trinomials:
(i) $p^2q + pq^2$
(ii) $7mn$
3.
Add the following algebraic expressions: $ab - bc$, $bc - ca$, $ca - ab$.
4.
Find the product of the following pair of monomials: $(4p)$ and $(q+r)$.
5.
Evaluate using the standard identity $(a-b)^2$: $99^2$.
SECTION B (15 Marks)(Short Answer Type - 3 Marks Each)
6.
Subtract $4a - 7ab + 3b + 12$ from $12a - 9ab + 5b - 3$.
7.
Simplify the expression using a suitable identity: $(2x + 5y)^2$.
8.
Using the identity $(x+a)(x+b) = x^2 + (a+b)x + ab$, evaluate $103 \times 104$.
9.
Simplify the following expression:
$(a+b)(2a-3b+c) - (2a-3b)c$
10.
Subtract $3pq(p-q)$ from $2pq(p+q)$.
SECTION C (15 Marks)(Long Answer Type - 5 Marks Each)
11.
Show that:
$(3x+7)^2 - 84x = (3x-7)^2$
12.
(a) Multiply the binomials: $(a^2 + 2b^2)$ and $(5a - 3b)$. [3 Marks]
(b) If $x - \frac{1}{x} = 4$, find the value of $x^2 + \frac{1}{x^2}$. [2 Marks]
13.
Using the identity $a^2 - b^2 = (a+b)(a-b)$, find the value of:
(i) $51^2 - 49^2$ [2.5 Marks]
(ii) $1.02^2 - 0.98^2$ [2.5 Marks]
