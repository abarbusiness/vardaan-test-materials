Q2. Classify the following polynomials as monomials, binomials, or trinomials: (i) $p^2q + pq^2$ (ii) $7mn$
[2 Marks]
(i) $p^2q + pq^2$ contains two unlike terms. Therefore, it is a Binomial. (1 Mark)
(ii) $7mn$ contains only a single term. Therefore, it is a Monomial. (1 Mark)
Q3. Add the following algebraic expressions: $ab - bc$, $bc - ca$, $ca - ab$.
[2 Marks]
To add the expressions, we arrange like terms together:
$(ab - bc) + (bc - ca) + (ca - ab)$ (½ Mark)
$= ab - bc + bc - ca + ca - ab$
Grouping like terms: $= (ab - ab) + (-bc + bc) + (-ca + ca)$ (1 Mark)
$= 0 + 0 + 0 = $ 0 (½ Mark)
Q4. Find the product of the following pair of monomials: $(4p)$ and $(q+r)$.
[2 Marks]
Using the distributive property of multiplication over addition:
$(4p) \times (q + r)$ (½ Mark)
$= (4p \times q) + (4p \times r)$ (1 Mark)
$= $ $4pq + 4pr$ (½ Mark)
Q5. Evaluate using the standard identity $(a-b)^2$: $99^2$.
[2 Marks]
We can write 99 as $(100 - 1)$. Thus, $99^2 = (100 - 1)^2$. (½ Mark)
Using identity $(a - b)^2 = a^2 - 2ab + b^2$, where $a = 100, b = 1$:
$= (100)^2 - 2(100)(1) + (1)^2$ (1 Mark)
$= 10000 - 200 + 1$
$= 9800 + 1 = $ 9801 (½ Mark)

Q6. Subtract $4a - 7ab + 3b + 12$ from $12a - 9ab + 5b - 3$.
[3 Marks]
We write the expression to be subtracted in brackets with a minus sign:
$(12a - 9ab + 5b - 3) - (4a - 7ab + 3b + 12)$ (1 Mark)
Opening the brackets (changing signs of the second expression):
$= 12a - 9ab + 5b - 3 - 4a + 7ab - 3b - 12$ (1 Mark)
Grouping like terms:
$= (12a - 4a) + (-9ab + 7ab) + (5b - 3b) + (-3 - 12)$
$= $ $8a - 2ab + 2b - 15$ (1 Mark)
Q7. Simplify the expression using a suitable identity: $(2x + 5y)^2$.

Using the identity: $(a + b)^2 = a^2 + 2ab + b^2$ (1 Mark)
Here, $a = 2x$ and $b = 5y$. Substituting these values:
$= (2x)^2 + 2(2x)(5y) + (5y)^2$ (1 Mark)
$= 4x^2 + 20xy + 25y^2$
$4x^2 + 20xy + 25y^2$ (1 Mark)
Q8. Using the identity $(x+a)(x+b) = x^2 + (a+b)x + ab$, evaluate $103 \times 104$.
[3 Marks]
We can rewrite the numbers as: $103 = (100 + 3)$ and $104 = (100 + 4)$
So, $103 \times 104 = (100 + 3)(100 + 4)$ (1 Mark)
Comparing with $(x+a)(x+b)$, we have $x = 100$, $a = 3$, $b = 4$.
Using identity: $100^2 + (3 + 4) \times 100 + (3 \times 4)$ (1 Mark)
$= 10000 + (7 \times 100) + 12$
$= 10000 + 700 + 12 = $ 10712 (1 Mark)
Q9. Simplify: $(a+b)(2a-3b+c) - (2a-3b)c$

$= a(2a - 3b + c) + b(2a - 3b + c) - [2ac - 3bc]$ (1 Mark)

$= $ $2a^2 - 3b^2 - ab - ac + 4bc$ (1 Mark)
Q10. Subtract $3pq(p-q)$ from $2pq(p+q)$.
[3 Marks]
First, simplify both expressions before subtracting:
Expression 1 (to subtract): $3pq(p - q) = 3p^2q - 3pq^2$ (½ Mark)
Expression 2 (from which to subtract): $2pq(p + q) = 2p^2q + 2pq^2$ (½ Mark)
Now, perform subtraction: Expression 2 - Expression 1
$(2p^2q + 2pq^2) - (3p^2q - 3pq^2)$ (1 Mark)
$= 2p^2q + 2pq^2 - 3p^2q + 3pq^2$
Grouping like terms: $(2 - 3)p^2q + (2 + 3)pq^2$
$= $ $-p^2q + 5pq^2$ (1 Mark)
SECTION C (15 Marks)
Q11. Show that: $(3x+7)^2 - 84x = (3x-7)^2$
[5 Marks]
We will solve this by expanding the LHS (Left Hand Side) and proving it equals the RHS (Right Hand Side).
LHS $= (3x+7)^2 - 84x$
Using identity $(a+b)^2 = a^2 + 2ab + b^2$ for $(3x+7)^2$:
$= [(3x)^2 + 2(3x)(7) + (7)^2] - 84x$ (1.5 Marks)
$= (9x^2 + 42x + 49) - 84x$ (1 Mark)
Grouping the 'x' terms together:
$= 9x^2 + (42x - 84x) + 49$
$= 9x^2 - 42x + 49$ (1 Mark)
Now observe the RHS: $(3x-7)^2$.
Expanding RHS using $(a-b)^2 = a^2 - 2ab + b^2$:
RHS $= (3x)^2 - 2(3x)(7) + (7)^2$
$= 9x^2 - 42x + 49$ (1 Mark)
Since LHS = RHS, the relationship is proved. (½ Mark)
Q12. (a) Multiply the binomials: $(a^2 + 2b^2)$ and $(5a - 3b)$.
(b) If $x - \frac{1}{x} = 4$, find the value of $x^2 + \frac{1}{x^2}$.
[5 Marks]
Part (a) [3 Marks]
Multiply term by term (FOIL method):
$(a^2 + 2b^2) \times (5a - 3b)$
$= a^2(5a - 3b) + 2b^2(5a - 3b)$ (1 Mark)
$= (a^2 \times 5a) - (a^2 \times 3b) + (2b^2 \times 5a) - (2b^2 \times 3b)$ (1 Mark)
$= $ $5a^3 - 3a^2b + 10ab^2 - 6b^3$ (1 Mark)
Part (b) [2 Marks]
Given: $x - \frac{1}{x} = 4$. Squaring both sides:
$(x - \frac{1}{x})^2 = (4)^2$ (½ Mark)
Using identity $(a-b)^2 = a^2 - 2ab + b^2$:
$x^2 - 2(x)(\frac{1}{x}) + (\frac{1}{x})^2 = 16$ (1 Mark)
The $x$ and $1/x$ in the middle term cancel out:
$x^2 - 2 + \frac{1}{x^2} = 16$
$x^2 + \frac{1}{x^2} = 16 + 2$
$= $ 18 (½ Mark)
Q13. Using the identity $a^2 - b^2 = (a+b)(a-b)$, find the value of:
(i) $51^2 - 49^2$
(ii) $1.02^2 - 0.98^2$
[5 Marks]
Part (i) [2.5 Marks]
Given expression: $51^2 - 49^2$
Here, $a = 51$ and $b = 49$. Applying the identity:
$= (51 + 49)(51 - 49)$ (1 Mark)
Solving the brackets:
$= (100) \times (2)$ (1 Mark)
$= $ 200 (½ Mark)
Part (ii) [2.5 Marks]
Given expression: $1.02^2 - 0.98^2$
Here, $a = 1.02$ and $b = 0.98$. Applying the identity:
$= (1.02 + 0.98)(1.02 - 0.98)$ (1 Mark)
Solving the brackets:
$= (2.00) \times (0.04)$ (1 Mark)
$= 2 \times 0.04 = $ 0.08 (½ Mark)
