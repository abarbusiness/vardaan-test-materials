SECTION A (10 Marks)
1.
Write the following set in Roster form:
$A = \{x \mid x \text{ is a vowel in the word "EQUATION"}\}$
[2 Marks]
Solution:
The word "EQUATION" contains the vowels E, U, A, I, O.
In roster form, the elements are listed separated by commas within braces. Order does not matter.
$$A = \{E, U, A, I, O\} \quad \text{or} \quad A = \{A, E, I, O, U\}$$
(Note: 2 marks for listing all 5 vowels inside curly braces correctly).
2.
Express the ratio $45\text{ cm}$ to $3\text{ meters}$ in its simplest form.
[2 Marks]
Solution:
To find the ratio, both quantities must be in the same unit.
We know, $1\text{ meter} = 100\text{ cm}$.
Therefore, $3\text{ meters} = 3 \times 100\text{ cm} = 300\text{ cm}$.
$$ \text{Ratio} = \frac{45\text{ cm}}{300\text{ cm}} = \frac{45}{300} $$ $$ = \frac{45 \div 15}{300 \div 15} = \frac{3}{20} $$
Answer: The required ratio is $3 : 20$.
3.
State whether the following sets are finite or infinite:
(i) Set of all stars in the universe.
(ii) Set of multiples of $5$ which are less than $100$.
[2 Marks]
Solution:
(i) Infinite Set. (The number of stars cannot be explicitly counted/has no end).
(ii) Finite Set. (The elements are $\{5, 10, 15, \dots, 95\}$, which can be counted and has an end).
4.
Find the value of $x$ if the numbers $3, 12, 15,$ and $x$ are in proportion.
[2 Marks]
Solution:
If four numbers $a, b, c, d$ are in proportion, then $a:b :: c:d$.
This means the product of extremes equals the product of means ($a \times d = b \times c$).
$$ 3 : 12 :: 15 : x $$ $$ 3 \times x = 12 \times 15 $$ $$ 3x = 180 $$ $$ x = \frac{180}{3} = 60 $$
Answer: $x = 60$.
5.
Find the cardinal number of the set $B = \{x \mid x \text{ is a prime number between } 10 \text{ and } 20\}$.
[2 Marks]
Solution:
First, list the elements of set $B$ in roster form. The prime numbers between $10$ and $20$ are $11, 13, 17,$ and $19$.
$$ B = \{11, 13, 17, 19\} $$ The cardinal number, denoted as $n(B)$, is the total number of distinct elements in the set.
Answer: $n(B) = 4$.
SECTION B (15 Marks)
6.
Divide ₹$1500$ between A and B in the ratio $2:3$.
[3 Marks]
Solution:
Total ratio parts = $2 + 3 = 5$ parts.
Total amount = ₹$1500$.
Value of $1$ part = $\frac{1500}{5} = \text{₹}300$.

Share of A = $2 \text{ parts} = 2 \times 300 = \text{₹}600$.
Share of B = $3 \text{ parts} = 3 \times 300 = \text{₹}900$.
Answer: A gets ₹$600$ and B gets ₹$900$.
7.
Let $P = \{1, 2, 3, 4, 5\}$ and $Q = \{2, 4, 6, 8\}$. Answer the following:
(i) Write down the set of elements present in P but not in Q.
(ii) Are P and Q equivalent sets? Give a logical reason for your answer.
[3 Marks]
Solution:
(i) Elements in P are $1, 2, 3, 4, 5$. Elements in Q are $2, 4, 6, 8$.
The elements present in P but NOT in Q are $1, 3,$ and $5$.
Set = $\{1, 3, 5\}$.

(ii) For two sets to be equivalent, they must have the same cardinal number.
$n(P) = 5$
$n(Q) = 4$
Answer: No, P and Q are not equivalent sets because their cardinal numbers are not equal ($5 \neq 4$).
8.
The ratio of the length to the width of a rectangular playground is $5:3$. If the length of the playground is $80\text{ m}$, calculate its width.
[3 Marks]
Solution:
Let the length be $5x$ and the width be $3x$.
Given, Length = $80\text{ m}$.
$$ 5x = 80 $$ $$ x = \frac{80}{5} = 16 $$
Now, calculate the width:
$$ \text{Width} = 3x = 3 \times 16 = 48\text{ m} $$ Answer: The width of the playground is $48\text{ m}$.
9.
Rewrite the following set in Set-builder form:
$C = \{5, 10, 15, 20, 25, \dots\}$
[3 Marks]
Solution:
Observing the pattern, the elements are multiples of $5$ starting from $5$ to infinity. These are natural numbers multiplied by $5$.
In Set-builder form, it can be written as:
$$ C = \{x \mid x \text{ is a multiple of } 5, x \in \mathbb{N}\} $$
Alternatively: $C = \{x \mid x = 5n, n \in \mathbb{N}\}$
10.
The ratio of the number of boys to girls in a school is $5:4$. If there are $800$ boys in the school, find the total number of students.
[3 Marks]
Solution:
Let the number of boys be $5x$ and the number of girls be $4x$.
Given, number of boys = $800$.
$$ 5x = 800 $$ $$ x = \frac{800}{5} = 160 $$
Total number of students = Number of boys + Number of girls
$$ = 5x + 4x = 9x $$
Substituting the value of $x$:
$$ = 9 \times 160 = 1440 $$ Answer: The total number of students in the school is $1440$.
SECTION C (15 Marks)
11.
The cost of $12$ identical pens is ₹$180$. Calculate using the unitary method:
(a) The cost of $25$ such pens.
(b) The number of pens that can be bought for ₹$300$.
[5 Marks]
Solution:
Step 1: Apply unitary method.
Cost of $12$ pens = ₹$180$
Cost of $1$ pen = $\frac{180}{12} = \text{₹}15$

(a) Cost of $25$ pens:
Cost of $25$ pens = Cost of $1$ pen $\times 25$
$$ = 15 \times 25 = \text{₹}375 $$
(b) Number of pens for ₹$300$:
Number of pens = $\frac{\text{Total Amount}}{\text{Cost of } 1 \text{ pen}}$
$$ = \frac{300}{15} = 20 \text{ pens} $$
Answers: (a) ₹$375$    (b) $20$ pens.
12.
Consider the set $S = \{a, b, c\}$.
(a) Write down all the possible subsets of the set $S$.
(b) Verify the mathematical property that the number of subsets is $2^n$, where $n$ represents the cardinal number of the set.
[5 Marks]
Solution:
(a) Finding all subsets:
A subset can have $0, 1, 2,$ or $3$ elements.
- Subset with $0$ elements: $\emptyset$ (Empty set)
- Subsets with $1$ element: $\{a\}, \{b\}, \{c\}$
- Subsets with $2$ elements: $\{a, b\}, \{b, c\}, \{a, c\}$
- Subset with $3$ elements: $\{a, b, c\}$ (The set itself)
All subsets: $\emptyset, \{a\}, \{b\}, \{c\}, \{a, b\}, \{b, c\}, \{a, c\}, \{a, b, c\}$.

(b) Verification:
Cardinal number of set S, $n(S) = 3$ (since there are 3 elements: a, b, c).
Formula for number of subsets = $2^n$
$$ 2^3 = 2 \times 2 \times 2 = 8 $$
By counting the list generated in part (a), we have exactly $8$ subsets.
Hence, the property is verified.
13.
Three partners Rohan, Rahul, and Raj invest ₹$30,000$, ₹$40,000$, and ₹$50,000$ respectively to start a small business. At the end of the year, they make a total profit of ₹$24,000$. Calculate the share of profit for each partner, assuming the profit is shared in the ratio of their original investments.
[5 Marks]
Solution:
Step 1: Find the ratio of investments.
Ratio = Rohan : Rahul : Raj
Ratio = $30,000 : 40,000 : 50,000$
Simplifying by dividing by $10,000$:
Ratio = $3 : 4 : 5$

Step 2: Calculate total parts.
Total parts = $3 + 4 + 5 = 12$ parts.
Total Profit = ₹$24,000$

Step 3: Calculate individual shares.
Rohan's Share = $\frac{3}{12} \times 24000 = 3 \times 2000 = \text{₹}6,000$

Rahul's Share = $\frac{4}{12} \times 24000 = 4 \times 2000 = \text{₹}8,000$

Raj's Share = $\frac{5}{12} \times 24000 = 5 \times 2000 = \text{₹}10,000$

Answer: Rohan receives ₹$6,000$, Rahul receives ₹$8,000$, and Raj receives ₹$10,000$.
